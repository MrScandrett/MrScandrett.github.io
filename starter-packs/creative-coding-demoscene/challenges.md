# Signal Garden challenges

## Level 1: Visual researcher

- Create a palette from a painting and explain its color relationships.
- Change the number, amplitude, and frequency of Wave Choir layers.
- Make the Star Tunnel travel backward without changing its geometry.
- Export three frames that feel meaningfully different.

## Level 2: Creative coder

- Add a Trails slider controlling Flow Field background alpha.
- Blend two octaves of `valueNoise` at different scales.
- Add pointer position as an input to one scene.
- Create a fourth scene using circles, rotation, and sine.

## Level 3: Demoscene designer

- Build a 60-second sequence that transitions automatically between scenes.
- Use the Web Audio API to react to microphone or generated oscillator data.
- Add a deliberate title card and end card.
- Keep the entire project lightweight and credit every external asset.

## Artist statement prompts

What rule generated your piece? Which variables did you constrain? Where does
repetition appear? Where does variation appear? What should the viewer notice first?
