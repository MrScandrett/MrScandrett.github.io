# Signal Run challenges

## Level 1: Scene builder

- Change floor color, arena size, and collectible positions.
- Add real collision to the three decorative platforms.
- Adjust speed, acceleration, jump, and camera distance one value at a time.
- Add a title label that identifies your game's setting.

## Level 2: Systems builder

- Add a countdown timer with a clear loss state.
- Add a launch gate that opens only after all cells are collected.
- Add checkpoints and respawn if the player falls below y = -10.
- Replace one code-generated object with your own imported model.

## Level 3: Game designer

- Build an enemy with patrol, detection, and chase states.
- Add two levels and carry only durable state between them.
- Add accessible settings for mouse sensitivity, volume, and reduced camera motion.
- Export a web build and write a five-case test plan.

## Definition of done

- The project opens without missing dependencies.
- A new player can discover the objective and controls.
- The game has a beginning, meaningful action, and visible win state.
- I can trace collection from physics signal to state change to HUD update.
