WHAT IS BUNDLED
---------------
Nothing third-party. There are no images, no fonts, no audio files, no icon
sets and no JavaScript libraries in this pack. The product "photos" are plain
coloured blocks drawn by CSS, so there is no borrowed art to credit.
Text is set in whatever the reader's system already uses (system-ui).

THE PRODUCTS ARE FICTIONAL
--------------------------
Nebula Supply Co. does not exist. The five products, their prices and their
descriptions were invented for this exercise. Do not present this page as a
real shop, and do not use a real company's name, logo or product photos in it.
Using a real business's branding on a fake storefront can be trademark
infringement, and it misleads people.

IF YOU ADD MEDIA
----------------
Add a line here for every file you add, listing:
  - what the file is (filename)
  - who made it (creator name)
  - where you got it (source URL)
  - what licence it carries (and whether attribution is required)

If you cannot answer all four, do not use the file. "I found it on a search
engine" is not a licence. Good places to look for material you are allowed to
use: openverse.org, Wikimedia Commons, and any site that states its licence
plainly. Check the licence on the file itself, not on the page linking to it.

Your own photos and drawings are always the safest choice, and they make the
project yours.
