      Why there is no checkout button

      A button that said "Buy now" and then did nothing would be a lie, and a button that said "Buy now" and then took a card number would be dangerous. A real store needs a payment provider and a server that checks every price again before it charges anyone. This pack has neither, so it does not pretend.

      README-FIRST.md has a full section on what a real store needs. Read it before you show this to anyone outside class.
