WHAT IS BUNDLED
---------------
Nothing third-party. There are no images, no fonts, no audio files, no 3D
models, no icon sets and no JavaScript libraries in this pack. The room plan is
drawn in code with the browser's own 2D drawing commands, and every exhibit is
a coloured block. Text is set in whatever the reader's system already uses
(system-ui).

That is why the pack works with no internet connection at all, and it is worth
noticing before you add a 3D library: the moment a page loads code from a web
address, it stops working when that address moves, when the network is
filtered, or when the wifi is down in the room where you are presenting.

THE EXHIBITS ARE PLACEHOLDERS
-----------------------------
"Orbit Study", "Geometry Game" and "Light Experiment" are descriptions of the
KIND of project that belongs in each slot, not real works. Replace them with
your own. Do not present a placeholder as finished work, and do not hang
somebody else's project in your gallery without asking them and crediting them
by name.

IF YOU ADD MEDIA
----------------
Add a line here for every file you add, listing:
  - what the file is (filename)
  - who made it (creator name)
  - where you got it (source URL)
  - what licence it carries (and whether attribution is required)

If you cannot answer all four, do not use the file. "I found it on a search
engine" is not a licence. Good places to look for material you are allowed to
use: openverse.org, Wikimedia Commons, and any site that states its licence
plainly. Check the licence on the file itself, not on the page linking to it.

3D models and environment images have exactly the same rules, and they are
easier to get wrong: a model downloaded from a sharing site often carries a
licence that forbids commercial use, or requires the creator's name to appear
somewhere a visitor can actually find it. Read it before you build it in.

IF YOU ADD A LIBRARY
--------------------
Name it, give its version, and give its licence. Then write one sentence saying
what your page does when that library fails to load — because one day it will,
and "the whole gallery disappears" is not an acceptable answer when the exhibit
list could have carried on working without it.

Your own photos, drawings and models are always the safest choice, and they
make the project yours.
