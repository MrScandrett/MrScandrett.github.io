THE WORKSHOP — CREATION HUB STARTER PACK
========================================

Original teaching material from Mr. Scandrett's ClassroomOS.
All HTML, CSS, JavaScript and written instructions in this pack were written
for this pack. Nothing was copied from another project.

WHAT IS IN IT
-------------
  index.html, style.css, script.js       the hub catalog
  creations/star-catcher/                a keyboard canvas game
  creations/bounce-lab/                  a 2D bouncing-ball simulation
  reference/index.html                   a finished version of challenge 4

Star Catcher and Bounce Lab are original works written for this pack. They are
not ports, forks or tutorials copied from elsewhere.

WHAT IS BUNDLED
---------------
Nothing third-party. There are no images, no fonts, no audio files, no icon
sets and no JavaScript libraries in this pack. Every shape on both canvases is
drawn in code with the browser's own 2D drawing commands, so there is no
borrowed art to credit. Text is set in whatever the reader's system already
uses (system-ui).

That is also why the whole pack works with no internet connection. A pack that
loads a library from a web address stops working the moment the address moves,
the network is filtered, or the wifi is down in the room you are presenting in.

IF YOU ADD MEDIA
----------------
Add a line here for every file you add, listing:
  - what the file is (filename)
  - who made it (creator name)
  - where you got it (source URL)
  - what licence it carries (and whether attribution is required)

If you cannot answer all four, do not use the file. "I found it on a search
engine" is not a licence. Good places to look for material you are allowed to
use: openverse.org, Wikimedia Commons, and any site that states its licence
plainly. Check the licence on the file itself, not on the page linking to it.

Sound effects and music have exactly the same rules as images. A game jam
track from a video is not free to use because the video was free to watch.

Your own drawings, photos and recordings are always the safest choice, and they
make the project yours.
