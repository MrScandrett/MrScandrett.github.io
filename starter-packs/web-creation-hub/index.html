    How a creation gets on this page

    1. Make a folder inside creations/ with its own index.html, style.css and JavaScript file.
    2. Make sure it works when you double-click that index.html on its own. If it only works from the hub, it is not finished.
    3. Add an entry to the CREATIONS array in script.js with a title, a category, a blurb, the written controls, and the credits.
    4. Reload this page. Your card is there, and the filter buttons already know about it.
