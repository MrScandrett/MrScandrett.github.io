# Signal Sweep challenges

Complete one challenge, run the game, and record what changed before continuing.

## Level 1: Confident editor

- Change the arena, player, signal, and glitch colors.
- Add IJKL as a second control scheme.
- Move the five signal starting positions.
- Display a one-sentence story under the title.

## Level 2: System builder

- Add three lives and a one-second safety period after damage.
- Add a countdown timer and a time bonus for each signal.
- Randomize signals without placing them on the player or glitch.
- Add a title state that begins only after Enter is pressed.

## Level 3: Game designer

- Create a second enemy with a different movement rule.
- Add a power-up that slows enemies for five seconds.
- Add sound with a mute button. Never autoplay loud audio.
- Create three levels that alter layout, speed, and objective.

## Evidence checklist

- My game can be played from start to win or loss.
- A new player can discover the controls without my help.
- I can explain input, update, collision, render, and state.
- I changed at least one rule rather than only changing colors.
