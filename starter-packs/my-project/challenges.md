# Project starter challenges

Do one at a time. Save, refresh, and check it works before starting the next.

## Level 1: Make it yours

- Change the page title, the `<h1>`, and the footer name.
- Pick a new `--accent` and `--bg` colour. Keep text easy to read.
- Add a new `<section>` with an `<h2>` and a paragraph about your project.
- Add an image: put it in an `images/` folder and use
  `<img src="images/your-file.jpg" alt="what the image shows">`.

## Level 2: Add structure

- Add a second page (`about.html`) and link the two pages to each other.
- Add a navigation bar in the header that appears on both pages.
- Make the button show a different message each click (hint: an array and a counter).
- Use a CSS grid to put two sections side by side on wide screens only.

## Level 3: Make it do something

- Build a tiny tool: a tip calculator, a word counter, or a random team picker.
- Save something with `localStorage` so it is still there after a refresh.
- Add a light/dark toggle that changes the CSS variables.
- Publish with GitHub Pages and share the link.

## Done means

- Every placeholder sentence is gone.
- The page works on a phone-width window (drag the browser narrow to check).
- There are no red errors in the console.
- Every image has useful `alt` text.
