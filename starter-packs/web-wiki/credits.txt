SIGNAL NOTES — WEB WIKI STARTER PACK
====================================

Original teaching material from Mr. Scandrett's ClassroomOS.
The three articles, all HTML, CSS and JavaScript, and all written instructions
in this pack were written for this pack. Nothing was copied from Wikipedia or
any other wiki.

WHAT IS BUNDLED
---------------
Nothing third-party. No images, no fonts, no audio, no icons and no JavaScript
libraries are included. Text is set in fonts already on the reader's computer,
so no font files ship with this pack.

ABOUT THE ARTICLES
------------------
The three articles are short original explanations of binary numbers, pixels
and loops. Every claim in them is arithmetic you can check by hand, and each
article's Sources line says how to check it. They are teaching notes, not a
reference work. If you publish this wiki, keep the Sources lines honest: say
where each article came from, and say plainly when something is your own
explanation rather than a cited fact.

IF YOU ADD AN ARTICLE
---------------------
Write it yourself. Copying and pasting text from another website into your wiki
is plagiarism even when it is accurate, and it is copyright infringement even
when you add a link. If you want to use someone's exact words, quote a short
passage, put it in quotation marks, and name the author and source right there.

IF YOU ADD MEDIA
----------------
Add a line here for every file you add, listing:
  - what the file is (filename)
  - who made it (creator name)
  - where you got it (source URL)
  - what licence it carries (and whether attribution is required)

If you cannot answer all four, do not use the file. "I found it on a search
engine" is not a licence. Openverse and Wikimedia Commons state licences
clearly; check the licence on the file itself, not the page that links to it.
Diagrams you draw yourself are always safe, and they usually explain your point
better than a borrowed photo.
