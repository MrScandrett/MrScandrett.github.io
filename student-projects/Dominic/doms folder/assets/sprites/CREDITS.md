# Original creature artwork

Mossback, Boulderkin, Glowfin, Emberkite and Gearpod are original vector designs created for Creature Battleground on 2026-11-15, dedicated to CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/. No third-party character images or traced artwork are used. Internal save identifiers retain old values solely for compatibility with existing progress.

Rebuild artwork: `node scripts/rights-remediation/creature-art.mjs` from the repository root.
