# Animal Kingdom Lesson — Medium Scope Definition

## Overview
A **standalone, self-contained HTML lesson** with embedded interactive classification game. No external dependencies beyond what your existing lessons use (vanilla JS, canvas optional). Designed to fit your `/lessons/` directory structure and reuse patterns from eht-ui and eht-interactivity.

---

## File Structure
```
lessons/
├── animal-kingdom.html          (main lesson page)
└── assets/
    ├── animal-sorter.js         (drag-drop logic, classification engine)
    └── animal-sorter.css        (styling for game UI)
```

The HTML will be self-contained (inline CSS for lesson sections), with the sorter game as a modular JS layer that can later be extracted to other classification lessons.

## Interactive Section (Drag-and-Drop Sorter)

### 2a. Sorter Layout
Located in a dedicated card section called **"Practice: Sort These Animals"** with three subsections:

#### **Classification Axis 1: Vertebrate vs. Invertebrate**
Two drop zones:
- **Vertebrates** (left side)
- **Invertebrates** (right side)

#### **Classification Axis 2: Three Habitats**
Three drop zones (revealed after Axis 1 is complete, or simultaneous—configurable):
- **Ocean**
- **Forest** (land-based, dense vegetation)
- **Desert** (arid, sparse vegetation)

**Total**: 5 drop zones, one unified animal card pool above.

### 2c. Drag-and-Drop Mechanics

**Interaction Flow:**
1. **Initial state**: All 23 animal cards displayed in a draggable pool above the zones
2. **User drags** a card onto a drop zone
3. **Visual feedback**:
   - Card snaps into place (smooth CSS transition)
   - Drop zone highlights on hover (light background shift)
   - Cursor changes to indicate droppability
4. **Validation** (on-place feedback):
   - ✓ **Correct placement**: Card locks in place, brief green highlight
   - ✗ **Incorrect placement**: Card bounces back to pool with red flash, no penalty
5. **Completion state**: When all cards are correctly sorted, show a "Success!" message with brief celebration animation

**No explicit scoring**, but students get clear visual confirmation of correctness.

---

### 2d. Sorting Rules

Each animal can only go in **one correct drop zone**. Rules are absolute (not fuzzy):

**Vertebrate/Invertebrate axis:**
- All vertebrates go left, all invertebrates go right (17 + 6 = 23)
- Can be sorted independently or integrated with habitat sorting

**Habitat axis (if running simultaneously):**
- **Ocean animals**: Salmon, Clownfish, Seahorse, Octopus, Starfish, Jellyfish, Whale, Penguin
- **Forest animals**: Frog, Salamander, Eagle, Parrot, Lion, Bat, Ant, Beetle, Snail
- **Desert animals**: Snake, Turtle, Crocodile

**Note**: Some animals (e.g., Lion) could fit multiple habitats. For this version, we pick ONE correct habitat per animal to keep logic simple. Future version could allow "multiple correct answers."

## User Experience Flow

### Student Perspective
1. **Read lesson** (2–3 min): Scroll through static sections, absorb characteristics, groups, adaptations
2. **See the challenge**: "Can you sort 23 animals into two groups?"
3. **Drag first animal**: Visual confirmation it works
4. **Continue sorting**: Get immediate green/red feedback per placement
5. **Complete**: All animals correctly sorted → "Success! You've mastered animal classification."
6. **Optional reset**: Button to clear and try again

### Teacher Perspective
- Lesson loads instantly (no network calls, no external assets)
- Game is self-contained and non-distracting
- Can be assigned as a check-for-understanding activity
- No login, no tracking, no data collection
- Easy to reset between class periods

## Visual Design

### Sorter Game UI
- **Background**: Soft green (--soft: #eef6ea), matching lesson theme
- **Drop zones**: Dashed borders (var(--accent2)), stacked vertically or in a 2-column layout depending on screen size
- **Animal cards**: White background, small border, subtle shadow, legible sans-serif
- **Feedback**: 
  - Green checkmark (✓) on correct placement
  - Red X (✗) on incorrect placement, with gentle bounce-back animation
  - Celebration message: "Great job! All animals sorted correctly!" in bold accent color

### Responsive Design
- **Desktop** (> 768px): Drop zones in 2 rows (vertebrate/invertebrate top, habitats bottom), animal pool above
- **Mobile** (≤ 768px): Drop zones stacked single column, smaller animal cards

## Limitations & Intentional Constraints

### What This Version Does NOT Include
- **Images**: Animals are text-based cards only (future iteration)
- **Scoring/points**: No numeric scoring; success is binary (all correct or not)
- **Time limits**: No countdown timer
- **Multiple rounds**: No "levels" or difficulty progression
- **Persistent data**: No progress saving between sessions
- **Audio**: No sound effects
- **Advanced validation**: Single correct zone per animal (no "multiple right answers")
- **Hints system**: No tooltips or difficulty toggle

### Why These Constraints?
Keep the scope to **core learning mechanics** (sorting + immediate feedback). These features can be added in a future "enhanced" version without redesigning the foundation.
