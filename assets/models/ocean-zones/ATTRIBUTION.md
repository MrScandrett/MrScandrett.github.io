## Hadal field profiles

Accurate open 3D models could not be verified for the following lesson taxa, so the interface presents clearly labeled field profiles and does not use generic substitutes: hadal amphipod (*Hirondellea gigas*), hadal sea cucumber (Elasipodida), hadal polychaete (Polychaeta), xenophyophore, and piezophile microbes.

License links and creator attribution also appear inside the lesson whenever a model is visible. Exact-source checks were made against the Sketchfab public model API on 2026-08-04.

The floating selector uses small locally cached thumbnails supplied with those Sketchfab model records. Their circular glass treatment is part of the lesson interface; the full model still loads only on request. The five hadal field-profile selector illustrations were generated for this lesson as one scientific specimen sheet, then separated into transparent local cutouts. They are illustrative profiles, not claimed specimen scans or 3D models.
