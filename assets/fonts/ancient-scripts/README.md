# Ancient script fonts

Unmodified Noto Sans Egyptian Hieroglyphs and Noto Sans Cuneiform Regular,
from https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf
(downloaded October 13, 2026). Distributed under SIL Open Font License 1.1;
see OFL.txt. Renamed locally to egyptian.ttf and cuneiform.ttf.

The lesson SVG diagrams use outlines from these fonts. They illustrate modern
standardized sign forms, not facsimiles of dated inscriptions.
