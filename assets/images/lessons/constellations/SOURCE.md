# Constellation illustration sources

These 16 optimized WebP illustrations are derived from the matching illustrations
in Stellarium's `modern` sky culture:

https://github.com/Stellarium/stellarium/tree/master/skycultures/modern/illustrations

The image-to-star anchor coordinates and constellation line figures come from:

https://github.com/Stellarium/stellarium/blob/master/skycultures/modern/index.json

Stellarium is distributed under the GNU General Public License, version 2. The
repository license is available at:

https://github.com/Stellarium/stellarium/blob/master/COPYING

The source PNG filenames are `orion.png`, `ursa-major.png`, `cassiopeia.png`,
`cygnus.png`, `aries.png`, `taurus.png`, `gemini.png`, `cancer.png`, `leo.png`,
`virgo.png`, `libra.png`, `scorpius.png`, `sagittarius.png`, `capricornus.png`,
`aquarius.png`, and `pisces.png`.
