Downloaded 2026-08-17. No modifications were made beyond renaming.

Note: the manual does not have a published before/after screenshot of the
"dark shading pinch" artifact itself, so `bevel-width-comparison.png` (three
cubes with increasing bevel width, showing the beveled corner's faceted
geometry) and `weighted-normal-panel.png` (the actual modifier settings used
to fix the shading) were used as the closest real, on-topic substitutes.
Lesson captions were adjusted to describe what each screenshot actually shows.
