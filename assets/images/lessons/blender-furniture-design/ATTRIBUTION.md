# Blender Furniture Design screenshot sources

Real screenshots used in `lessons/blender-furniture-design.html`, sourced from
the official Blender Manual at docs.blender.org. Manual content (including
embedded screenshots) is licensed **CC BY-SA 4.0**
(https://docs.blender.org/manual/en/latest/copyright.html).

The Mirror Modifier manual page (https://docs.blender.org/manual/en/latest/modeling/modifiers/generate/mirror.html)
contains only a single screenshot (the modifier's settings panel), not a
before/after pair of a correctly- vs incorrectly-mirrored mesh. The closest
real before/after screenshot pair in the manual illustrating symmetric vs.
mismatched mesh geometry is on the Symmetrize page (a related but distinct
mesh operation that also produces a mirrored/symmetric result from one half
of a mesh). Those two screenshots were used instead, with captions in the
lesson written to honestly describe them as Symmetrize screenshots rather
than mislabeling them as Mirror modifier output.
