Notes:
- `uv-checker-grid.webp` shows the UV Editor with an unwrapped UV map (a
  cross-shaped cube-like net) and a UV Grid checker test texture — the manual's
  original caption is "UV Editor with a UV map and a test grid texture."
- `three-point-light-rig.webp` shows the manual's "Standard three-point light rig"
  figure: Top/Front/Right orthographic views of a key, fill, and rim light placed
  around a subject, plus the resulting render. This page is only available in the
  archived 2.79 version of the manual (current manual pages don't include an
  equivalent lighting-rig diagram), but it is still official Blender documentation
  content under the same CC BY-SA 4.0 license.
