# 3D design teaching visuals

- `wood-base-color.webp`, `wood-roughness.webp`, `wood-normal.webp`: 1K maps from [Fine Grained Wood](https://polyhaven.com/a/fine_grained_wood), Rob Tuytel / Poly Haven, [CC0](https://polyhaven.com/license). Downloaded through the Poly Haven file API on 2026-10-18 and resized to 640 px WebP for classroom pages. The normal map is the OpenGL version.
- `print-in-place-fidget-cube.webp`: [Print in place Fidget Cube.jpg](https://commons.wikimedia.org/wiki/File:Print_in_place_Fidget_Cube.jpg), Gary C Martin, [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). Downloaded from Wikimedia Commons on 2026-10-18 and resized to 960 px WebP.
- `desk-stationery-perspective.webp` and `desk-stationery-top.webp`: renders of [Stationery Supplies](https://polyhaven.com/a/stationery_supplies), Mateusz Sadek / Poly Haven, [CC0](https://polyhaven.com/license). Downloaded from Poly Haven on 2026-10-18, resized to about 900 px, and composited on an off-white background.
- All `.svg` files here are original ClassroomOS diagrams generated by `scripts/build-design3d-teaching-figures.py`; they contain no outside imagery.
