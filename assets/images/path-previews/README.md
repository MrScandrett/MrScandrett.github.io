# Learning path previews

Original SVG concept diagrams authored for paths.html. These are schematic overviews, not photographs or scientific measurements. Each names three concepts from its lesson. No external imagery is embedded in these diagrams.

`data/path-lesson-images.json` maps every lesson shown in paths.html to an explicit preview and descriptive alternative text. Existing local images retain their existing provenance in their lesson asset folders and assets/IMAGE_SOURCES.md. Edit the mapping when adding a path lesson; do not substitute unrelated module artwork.
