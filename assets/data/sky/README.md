# Sky data

`allsky.json` is generated by `node scripts/build-allsky-data.mjs` for the All-sky map mode of
`lessons/cosmology/constellations.html`. Do not edit it by hand.

- IAU constellation boundaries, star figures, names and stars to magnitude 5.6:
  [d3-celestial](https://github.com/ofrohn/d3-celestial) by Olaf Frohn, BSD 3-Clause.
- Messier and other bright deep-sky objects:
  [OpenNGC](https://github.com/mattiaverga/OpenNGC) by Mattia Verga, CC BY-SA 4.0.
  The `dso` array in `allsky.json` is derived from it and is shared under the same license.
