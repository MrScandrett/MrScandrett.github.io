# Blender and Game Asset Studio source policy

This record covers the Blender Fundamentals and Game Asset Studio pathways.

## Current asset audit

- No AI-generated bitmap, texture, HDRI, skybox, or 3D model file is used by
  these pathways as of 2026-08-27.
- `models/animation-studio/quaternius-human.glb` is a CC0 Universal Base
  Character by Quaternius. Its source, license, prepared-copy provenance, and
  SHA-256 checksum are recorded in `models/animation-studio/LICENSE.md`.
- The Blender lesson screenshots under `images/lessons/blender-*/` are authentic
  Blender Manual screenshots, not generated art. Their CC BY-SA 4.0 source
  records remain in each directory's `ATTRIBUTION.md`.
- Canvas textures and primitive furniture previews in the Game Asset Studio are
  deterministic teaching code, not imported or AI-generated asset files.

## Approved CC0/public-domain starting libraries

| Library | Suitable assets | License and provenance |
| --- | --- | --- |
| [Poly Haven](https://polyhaven.com/) | PBR textures, photographic HDRIs/skyboxes, 3D models | [CC0](https://polyhaven.com/license); Poly Haven states its assets are human-made and exclude generative AI. |
| [Quaternius](https://quaternius.com/) | Stylized characters, animations, props, vehicles, environments | Individual pack pages identify the assets as CC0. |
| [Kenney](https://kenney.nl/assets) | Classroom-friendly 2D and 3D game assets | [All asset-page downloads are CC0](https://kenney.nl/support). |

## Intake checklist

For every downloaded asset, keep the exact asset name, creator/library,
asset-page URL, license, download date, and a note describing modifications.
Retain any included license file. Do not add an asset when its creator, license,
or generation method is unclear.
