      Your first part in Forge

      1. Choose a part. Search the library for a mechanism, fidget, or everyday object. Each part remembers its measurements.
      2. Make it yours. Use sliders or type values. The 3D view updates as you work. Undo brings back earlier edits.
      3. Check, then export. Read the Checks tab. Download an STL to slice for printing, or a GLB for a game.

      Changes stay in this browser automatically. Save a copy to keep a project file you can move to another computer.

      Shortcuts: Ctrl/⌘ Z to undo · Ctrl/⌘ Shift Z to redo · Ctrl/⌘ S to save a copy · F to fit the view. Focus the preview and use arrow keys to orbit.
