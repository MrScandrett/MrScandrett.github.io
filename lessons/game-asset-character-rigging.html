Lesson 05 · 75 minutes · Character setup

Build the invisible machine inside.

A rig connects a controllable skeleton to a mesh. Good rigging is not about having many bones; it is about placing useful joints, assigning predictable influence, and proving the character can hold the poses the game needs.

01 / READY

Prepare the mesh

Rig only a model that is ready to deform.

POSE

Neutral stance

Use a relaxed A-pose or T-pose with limbs separated enough to select and weight.

TOPOLOGY

Loops at joints

Elbows, knees, shoulders, and hips need enough well-placed loops to bend without collapsing.

SYMMETRY

Mirror before rigging

Correct the centerline and left/right shape before weights make changes harder.

TRANSFORMS

Apply scale and rotation

Character and armature should share clean transforms and the same world orientation.

Backup now: Save character_pre_rig.blend. Rigging changes many relationships at once; a clean restore point saves time.
02 / BONES

Anatomy as hinges

Place joints where the volume should rotate.

  1. Add one armature at the character center.Enable In Front so bones remain visible through the mesh.
  2. Build the central chain.Root or hips → spine → chest → neck → head. Keep the root useful for moving the whole character.
  3. Extrude one limb side.Upper arm → forearm → hand; thigh → shin → foot. Place elbow and knee joints at the bend center.
  4. Name with side suffixes.Use consistent .L and .R names so Blender can mirror correctly.
  5. Symmetrize the armature.Verify the mirrored bones point and roll consistently.

In Edit Mode, you change the rest structure. In Pose Mode, you test and animate that structure. Do not “fix” rest placement by posing bones.

03 / BIND

Connect mesh to skeleton

Parent with automatic weights—then inspect.

  1. Select mesh, then armature.The armature must be the active object.
  2. Parent with Automatic Weights.Blender adds an Armature modifier and vertex groups named for deforming bones.
  3. Enter Pose Mode.Rotate one joint at a time through a realistic range.
  4. Undo extreme test poses.Return to the rest pose before editing weight problems.

SIM / RIG

Weight-paint simulator

Paint a clean elbow bend—on the character you'll animate next.

This is the same rigged Quaternius dummy the animation lesson uses, so the joints you weight here are the joints you'll pose there. Choose the upper-arm or forearm bone, set brush strength, then click the mesh near the elbow to assign influence. Blue follows the upper arm; red follows the forearm. Bend the elbow to expose stray weights, then return near rest before you keep painting—the same return-to-neutral habit real riggers use to keep brush strokes predictable.

04 / PAINT

Repair influence

Fix deformation with small, testable weight changes.

SymptomInspectRepair
Torso moves with handUnexpected hand weights on torso verticesSubtract influence and normalize
Elbow pinches sharplyToo few loops or abrupt weight boundaryAdd/support topology or smooth transition
Both sides moveCenterline or mirrored group spillClean left/right groups and mirror carefully
Foot collapsesAnkle joint placement and foot weightsReposition in rest pose, then repaint
Weight-paint loop: Pose the problem → identify the vertices → return near neutral → add/subtract/smooth a little → normalize → pose again. Large blind brush strokes create new problems.
05 / PROVE

Pose sheet

Run a deformation stress test.

Test: arms forward and overhead, elbows near 90°, deep knee bend, one-leg stance, torso twist, head turn, and a curled crouch. The goal is not perfect anatomy; it is predictable volume for the character’s actual motion range.

Remix challenge

Add non-deforming control bones for hands or feet. Confirm they help posing but do not create unwanted vertex groups or game-engine deformation bones.
