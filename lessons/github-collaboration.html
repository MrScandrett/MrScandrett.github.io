00 / ORIENT

One platform, three powers

This is not simply cloud storage. GitHub combines a project home, a detailed memory of change, and a structured conversation about what should happen next.

Remember

Collaborate

Launch

2008

A social layer for software

GitHub launched in 2008 as a place to host Git repositories and collaborate on code. Its big idea was human: make change visible, discussable, reviewable, and reusable. Today the same workflow can support a science dashboard, club website, game prototype, hardware documentation, art portfolio, research notebook, or almost any idea that benefits from files plus a clear history.

01 / MODEL

Git is the memory. GitHub is the meeting place.

Keep these two ideas separate and the rest of the system becomes much easier to understand.

Git

A version-control system that tracks snapshots of files. It can work locally on one computer without GitHub.

≠

GitHub

An online platform that hosts Git repositories and adds accounts, issues, pull requests, reviews, project tools, and Pages hosting.

Repository

The project folder, its files, and the history of those files.

Commit

A named checkpoint: what changed, who changed it, and when.

Branch

A safe line of work where an idea can grow without disturbing the main version.

Issue

A focused conversation about a task, question, proposal, or problem.

Pull request

A request to compare, discuss, test, and possibly merge one branch into another.

Merge

The act of bringing approved changes together into the shared line of work.

05 / SHIP

Publish a first website with GitHub Pages

This browser-only route avoids the command line. GitHub’s labels can change over time, so use the linked official guide if the interface differs.

1

Create your account safely

Students must meet GitHub’s age requirement (13+ in the U.S.; local minimum ages may differ). Use a unique password, enable two-factor authentication, and do not put private information in the username or profile.

2

Create a repository

Select + → New repository. Use a short lowercase name such as cloud-guide. For free Pages, choose Public. Turn on Add a README, then create it.

3

Add the home page

Select Add file → Create new file. Name it exactly index.html. Add your HTML, preview it, and commit with a message that describes the change.

4

Turn on Pages

Open Settings → Pages. Under Build and deployment, choose Deploy from a branch, then main and /(root). Save.

5

Open and test the URL

Your project site normally appears at https://USERNAME.github.io/REPOSITORY/. Publishing can take a few minutes. Test navigation, mobile layout, keyboard use, and image paths.

6

Improve through branches

Create an issue for one improvement, make a branch, commit the change, open a pull request, ask for a focused review, then merge after testing.

Pre-publish gate

0 of 4 release checks complete.

06 / DECIDE

Know what belongs on GitHub—and what does not

GitHub Pages hosts static files. Anything committed to a public repository can be copied, even if you delete it later. Treat every public commit as permanent.

Before an account or a publish

  • Under 13? Do the planner and simulations without an account; use a teacher-approved school platform instead.
  • Public means public. Use project names, not personal details. Never publish class lists, private photos, precise schedules, or student locations.
  • Secrets never go in code. API keys, passwords, database credentials, and private tokens do not belong in HTML or a public repository.
  • Credit creators. A file being online does not mean you may reuse it. Check its license and add attribution.
Great fit

Static websites, portfolios, browser games, public data stories, documentation, design prototypes, open-source code, and project planning.

Needs another service

Logins, live databases, payments, private forms, or server-side code. GitHub can store the code, but Pages alone cannot safely run the backend.

Do not publish

Passwords, secret keys, private student data, copyrighted uploads without permission, harmful code, or anything that exposes someone’s safety.
