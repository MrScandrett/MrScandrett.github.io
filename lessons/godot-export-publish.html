02 / EXPORT

Desktop build

Create a build for the target computer.

  1. Install export templates.Open Editor → Manage Export Templates and install the version matching your editor.
  2. Add a preset.Open Project → Export and add Windows Desktop, macOS, Linux, or Web.
  3. Choose a clean output folder.Use a folder such as build/windows; do not export over project source files.
  4. Export Project.Create a release build and keep all generated companion files together.
  5. Test outside Godot.Close the editor, launch the build, and complete the game from beginning to end.
Version match matters: Export templates must match the installed Godot editor version. A mismatch is a common reason the Export button stays unavailable.
03 / WEB

Browser option

Use Compatibility rendering for a web build.

Godot 4 web exports use WebAssembly and WebGL 2. Export the main file as index.html, keep every generated file together, and serve the folder from a web server rather than opening the file directly.

Good web fit

Small GDScript project, Compatibility renderer, compressed textures, and modest audio.

Choose desktop instead

Large 3D scenes, unsupported rendering features, C# scripts, or strict performance needs.

GitHub Pages note: Export without threads unless the host is configured for the cross-origin isolation headers required by threaded web builds.
04 / TEST

Release test

Test behavior, environment, and understanding.

Smoke test

Launch, start, collect, take damage, pause, win, retry, quit.

Fresh-machine test

Run on a computer without the Godot editor or project source.

Input test

Try keyboard, mouse capture, window focus, and any supported gamepad.

Observer test

Watch someone play without coaching. Record every point of hesitation.

Bug report format

Expected: what should happen. Actual: what happened. Steps: exact actions to repeat it. Evidence: screenshot, video, or error message.

05 / SHIP

Showcase package

Help a new player begin in ten seconds.

  • Write a one-sentence goal: “Collect five energy cells while avoiding the patrol drone.”
  • Show WASD, mouse, jump, and pause controls before play.
  • Capture one clear screenshot that shows the player, goal, and threat.
  • Credit every external model, texture, font, and sound.
  • Include the Godot version and target platform.
