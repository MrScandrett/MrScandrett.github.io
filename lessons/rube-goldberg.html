Engineering notebook · Grades 5–9 · 50 minutes

Make it complicated.

Complete one tiny task with a wonderfully ridiculous chain of energy transfers. Then think like an engineer: predict, test, find the first failure, and change one variable.

Mission brief

Can every output become the next input?

Learning targetI can trace energy through a chain reaction, diagnose its first failure, and improve the design with evidence.

Success looks like this

  • I name the input, transfer, and output at each stage.
  • I distinguish a simple machine from an energy source or trigger.
  • I change one variable at a time and use the result as evidence.
  • I can explain why a funny, complicated path can still be carefully engineered.

01 · Read the mechanism

A machine is a story told by forces.

Rube Goldberg (1883–1970) trained as an engineer before becoming a cartoonist. His invention cartoons made fun of overcomplicated solutions: a tiny job took a long, labeled sequence of ordinary objects. Today, builders turn that visual joke into a real engineering challenge.

IN

Input

The push, pull, stored energy, or motion that begins one stage.

Δ

Transfer

Energy moves or changes form: gravitational to kinetic, elastic to kinetic, or motion from one object to another.

OUT

Output

The stage produces a motion or force strong and precise enough to trigger what comes next.

MA

Simple machine

A lever, wheel and axle, pulley, inclined plane, wedge, or screw changes a force’s size or direction.

Σ

System

The complete chain. A stage can work alone while the system still fails at a connection.

↻

Iteration

Test, observe, revise, and test again. A failed run is useful data when you identify where and why.

  1. Ball loses gravitational potential energy
  2. Ball gains kinetic energy
  3. Collisions topple dominoes
  4. Lever redirects the force
  5. Weight turns the wheel
  6. Bell converts motion to sound

02 · Test the chain

Debug the bell-ringer.

Change the ramp angle, domino spacing, and counterweight. Predict the first failure before each run. The best engineers do not change everything at once.

Machine 06-B · Ring the bell

Watch the yellow energy marker move. When the chain stops, the red stage is the first place where the output could not trigger the next input.

READY TO TEST
Plan your test.

Make a prediction, choose one variable to change, then run the machine.

  1. 1 · Ramp
  2. 2 · Dominoes
  3. 3 · Lever
  4. 4 · Weight
  5. 5 · Wheel
  6. 6 · Bell

Three-run investigation

  1. Run the starting setup. Record the first failed stage.
  2. Change only the variable that could fix that failure.
  3. Run again. Did the failure move farther down the chain?
  4. Find a successful setup. Explain which thresholds your settings met.
Ramp evidence

A steeper ramp gives the ball more speed by the time it reaches the dominoes. In this model, angles below 16° stall.

Spacing evidence

Dominoes must reach one another. In this model, gaps greater than 3.5 cm break the collision chain.

Weight evidence

The falling weight must provide enough turning effect. Below 3 units, the wheel does not pull the bell cord far enough.

System evidence

Passing one threshold does not guarantee success. Every connection must work during the same run.

04 · Engineer it for real

Tabletop challenge: deliver a note.

Build a machine that moves a folded paper note into a cup. The chain must be safe, resettable, and understandable to someone who did not build it.

6+distinct energy transfers
3+types of simple machine
1variable changed per test
3successful runs in a row

Suggested materials

  • Cardboard, paper cups, craft sticks, tape, and string
  • Dominoes or blocks, toy wheels, marbles, and binder clips
  • Books or boxes for stable height
  • A folded note and a wide, unbreakable target cup

Design cycle

  • Sketch: draw arrows and label each input and output.
  • Build backward: make the final note drop reliable first.
  • Test in sections: connect two stages before connecting six.
  • Revise: record the first failure and one useful change.
Safety boundary: Use only low-energy classroom materials. No flames, sharp projectiles, glass, mains electricity, animals, or people as machine parts. Wear eye protection if an object could fly, and get adult help before using tools.

05 · Exit check

Can you read the chain?

1. A ball rolls down a ramp. Which energy change best describes the motion?

2. The first three stages work, but the light weight cannot turn the wheel. What should you change first?

3. Why change only one variable during a test?
