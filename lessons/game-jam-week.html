What Is a Game Jam?

Game jams are real events in the professional world. Ludum Dare, the world's oldest online jam (running since 2002), sees 3,000+ entries in 72 hours. Global Game Jam is the world's largest, held simultaneously in 100+ countries. Many successful commercial games — including Superhot and Untitled Goose Game — started as jam prototypes.

The rules of your classroom jam:

Classroom Game Jam Rules:
① You have 5 days — Monday through Friday.
② Build a game in the engine or tool of your choice.
③ The game must be playable from start to "game over" (or winning state).
④ On Friday, you demo your game to the class for 3–5 minutes.
⑤ Done beats perfect — a simple game that works beats an ambitious game that crashes.

The 5-Day Jam Sprint

Follow this day-by-day plan. Resist the urge to jump to features — foundation first, features second, polish last.

Mon
Day 1
Design Day — No Code
  • Write your GDD (use the builder above)
  • Sketch 2–3 screens on paper (menu, gameplay, game over)
  • Find or decide on a 5-item asset list (what sprites/sounds you need)
  • Set up your VS Code project folder and get Live Server running
Tue
Day 2
Foundation Day — Core Loop Only
  • Get the player moving and responding to input
  • Add one obstacle or enemy (even as a rectangle placeholder)
  • Implement the lose condition (game over screen)
  • Goal: the game is playable but ugly by end of day
Wed
Day 3
Features Day — Mechanics & Feedback
  • Add score, timer, or health system
  • Add sound effects (at least one for hit/lose)
  • Implement difficulty scaling (enemies get faster over time)
  • Replace placeholder art with your actual sprites
Thu
Day 4
Polish Day — Feel & Flow
  • Add a proper start screen (title, "Press Space to play")
  • Add screen shake, particle effects, or color flash on impact
  • Add background music
  • Fix the top 3 bugs your playtesters find
  • Freeze new features — only polish from here
Fri
Day 5
Showcase Day — Demo & Celebrate
  • Final bug fixes (one hour max)
  • Prepare your 3-minute demo: show gameplay, explain your concept
  • Tell the class: what went well, what you'd do differently
  • Play everyone else's games — give specific, constructive feedback

Showcase Day Checklist

Click each item as you complete it before Friday's demo:

  • Game runs without crashing from start to game over
  • Start screen explains the goal and controls
  • Restart button works after game over
  • Score or progress is visible during play
  • At least one sound effect plays during gameplay
  • Game has a clear lose condition the player understands
  • Tested on a second computer or phone (not just your machine)
  • Practiced the demo: can explain the game in under 60 seconds
  • Prepared one thing you learned and one thing you'd change
  • Project folder is backed up (USB, cloud, or GitHub)

Tips from Experienced Jammers

✅ Do

  • Commit your code to Git every day (or every hour during jams)
  • Playtest with someone who didn't build the game — you'll miss obvious problems
  • Use free licensed assets from itch.io, OpenGameArt, or Freesound
  • Build the core loop first and get it fun before adding anything else
  • Write a cut list — features go there when scope creep hits
  • Pick a tiny-loop archetype (catch, dodge, maze…) before you pick a story

❌ Don't

  • Start with art — placeholder rectangles are fine. Art can come Thursday
  • Add features on Day 4 or 5 — only fix bugs and polish
  • Change your game concept mid-week unless the original is genuinely unworkable
  • Aim for perfection — aim for playable and interesting
  • Work alone if you can work in a team — jams are more fun together

Learning Goals

  • Write a complete mini GDD before coding
  • Identify over-scoped features and cut them intentionally
  • Follow a day-by-day sprint structure for a 5-day build
  • Demo a game to peers with a clear, confident 3-minute pitch

The Magic of Constraints

Jams have strict time limits for a reason: constraints force creativity. When you can't spend 3 weeks perfecting the controls, you find the simplest version that works — and often that's the version that's most fun.

Vertical Slice

Game studios use the concept of a "vertical slice" — one complete, polished section of a game showing all planned features working together. Your jam game should be a tiny vertical slice: shallow in content, but complete in experience.

Famous Real Game Jams

Ludum Dare
Online, 72-hour solo jam, runs 3× per year. A theme is announced on Friday night; your game must be submitted by Monday morning.
Global Game Jam
The world's largest jam — 48 hours, held in January at 800+ locations worldwide. Team-based.
GMTK Game Jam
Run by YouTube channel Game Maker's Toolkit. 48 hours, 10,000+ entries, single theme twist. Very educational.
itch.io Jams
Hundreds of themed jams run continuously on itch.io — horror, accessibility, nature, retro. Filter by upcoming jams.
