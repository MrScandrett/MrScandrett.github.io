Work like a web designer

Your repeatable routine

  1. Read and predict. Say out loud what one change should do before you make it.
  2. Edit and save. Change your own source files in VS Code — never only the browser's inspector.
  3. Run and inspect. Refresh, then compare the result against your prediction.
  4. Explain and keep evidence. Write down what worked, what broke, and the repair that fixed it.

That loop is the whole job. Professional web developers repeat it hundreds of times a day; the only thing that changes is the size of the change.

Your final demonstration
