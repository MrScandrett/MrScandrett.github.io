01

Plan

Measure before you model

Write the brief first.

1

Pick a piece

Chair, stool, side table, or shelf. A chair is the best first project — it forces you to solve legs, a seat, and a back.

2

Record real dimensions

A dining chair is roughly 0.45m wide, 0.45m deep, seat height 0.45m, back height 0.9m. Measure a real chair if you can.

3

Add a scale reference

Add a 1.7m cube nearby before modeling — it is the fastest way to catch a chair that is quietly the size of a bus.

CheckpointYou have three written numbers (width, depth, seat height) before opening the Add menu once.
02

Block out

Big shapes first

Prove the silhouette with boxes.

Box modeling means starting with a cube and reshaping it, instead of sculpting or drawing curves. Resize one cube into the seat, duplicate it for the back, and duplicate again for one front leg.

  1. Seat

    Scale a cube to seat width × depth × a thin thickness (about 0.04m).

    Cube → seat
  2. Back

    Duplicate (Shift+D) the seat, rotate it upright with R X 90, and move it to the rear edge.

    Duplicate → back
  3. One front leg

    Add a new cube, scale it into a thin vertical post, and position it under one front corner of the seat.

    Cube → leg
  4. One back leg

    Duplicate the front leg and move it to the back corner on the same side.

    Duplicate → leg
Model only one sideEvery part above sits on just the +X half of the chair. The other half doesn't exist yet — that's the next section's job.
03

Mirror

One modifier, perfect symmetry

Add the Mirror modifier to each part.

Select each object, open the Modifier Properties tab, and add Mirror. By default it reflects across the object's local X axis through its own origin — so origin placement matters.

⇄

Reflect geometry

Mirror modifier

Duplicates and flips a mesh across an axis in real time. Edits to one side update the other automatically.

⌖

Where the mirror happens

Object origin

The mirror axis passes through the object's origin, not the world center. Move the origin to the seat's true centerline before mirroring.

◫

Merge the seam

Clipping + Merge

Enable Clipping so vertices near the mirror line can't be dragged through it, leaving a gap.

Set the origin first

Select an object, snap the 3D cursor to the chair's true centerline, then Object → Set Origin → Origin to 3D Cursor. Do this before adding Mirror or the reflection will land in the wrong place.

04

Shade

Make it look manufactured

Bevel every edge that would catch light.

A real chair leg is never a perfectly sharp 90° edge — manufacturing always leaves a small radius. That tiny bevel is what lets light wrap around the edge instead of cutting to pure black.

  1. Add a Bevel modifier

    Select each part, add Bevel, and set Amount to roughly 0.003–0.006m with 2–3 segments.

    Bevel modifier
  2. Shade Auto Smooth

    Right-click the object → Shade Auto Smooth. This smooths curved surfaces while keeping sharp corners crisp, based on a face angle threshold.

    Shading
  3. Order the modifier stack

    Keep Bevel above (evaluated before) any Subdivision Surface modifier, or the bevel will be smoothed away.

    Stack order
05

Build

Hands on

Finish the chair.

  1. Block the four parts

    Seat, back, and one pair of legs (front + back on one side), sized from your written dimensions.

    Block-out
  2. Fix each origin

    Set each part's origin to sit exactly on the chair's centerline (X = 0).

    Origins
  3. Mirror every part

    Add a Mirror modifier to the seat, back, and both legs.

    Mirror ×4
  4. Bevel everything

    Add a Bevel modifier to each part and enable Shade Auto Smooth.

    Bevel + shade
  5. Parent the parts

    Select all four, then the seat last, and press Ctrl+P → Object (Keep Transform) so the whole chair moves as one unit.

    Parent
  6. Rename, apply, save

    Rename every part in the Outliner, apply the Mirror and Bevel modifiers if this is your final version, then Ctrl+S.

    Finish
Mirrored geometry appears on the wrong side, or overlapping?
  • The object's origin isn't on the centerline — redo Set Origin → Origin to 3D Cursor with the cursor snapped to X = 0.
  • Check the Mirror modifier's axis checkboxes — only X should usually be enabled for a left/right mirror.
  • If halves overlap at the seam, enable the modifier's Merge option to weld the center vertices.

Learning goals

  • Box-model at real-world dimensions
  • Place an origin deliberately before mirroring
  • Use the Mirror modifier for guaranteed symmetry
  • Bevel and Auto Smooth for believable shading
  • Parent multiple parts into one movable object

Requires

  • Lesson 01: Interface & Navigation

Save habit

Save right after your first successful Mirror modifier — it's the step most worth protecting.

Key vocabulary

Box modeling
Building a shape by reshaping a primitive cube instead of sculpting.
Mirror modifier
Reflects geometry across an axis through the object's origin.
Origin
An object's pivot point — separate from its geometry's visual center.
Shade Auto Smooth
Smooths curved faces while preserving sharp corners by angle.
Parenting
Linking objects so a parent's transform moves its children too.
