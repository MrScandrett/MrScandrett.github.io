First upload

Meet the Arduino IDE

The IDE (Integrated Development Environment) is where you write, check, and upload code called a sketch. Three buttons matter most: Verify checks your code for errors without touching the board, Upload compiles it and sends it over USB to the Arduino's memory, and the Serial Monitor opens a window that shows text your sketch sends back — your board's first "hello."

Sketch anatomy

setup() vs loop()

Every Arduino sketch has exactly two required functions. Press run and watch how many times each one actually executes.

setup()

void setup() {
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

Runs once, the instant the board powers on or resets. Perfect for one-time setup: naming pins, starting Serial, initializing variables.

loop()

void loop() {
  digitalWrite(LED, HIGH);
  delay(1000);
  digitalWrite(LED, LOW);
  delay(1000);
}

Runs forever, immediately repeating from the top the instant it reaches the bottom. This is the robot's feedback loop, made literal.

Ready — press run to trace execution.

Hardware basics

Blink: Hello World, but with light

delay(1000) pauses for 1000 milliseconds (one second). Drag the slider to change the blink sketch's delay value and watch the simulated board — and its Serial Monitor — respond in real time.

LED_BUILTIN · OFF

This one number controls both the HIGH delay and the LOW delay in the sketch above.

Challenge

Send a message in Morse code

Modify Blink so the delay pattern spells something. A short flash is a dot, a long flash is a dash. Type a short word (letters and numbers only) and watch your virtual LED blink it out.

Real code: build an array of dot/dash durations, then loop through it turning the LED on for each duration with a short pause between.

int dot = 200, dash = 600;

Bigger picture

How does neuroscience relate to robotics?

A neuron and a microcontroller solve the same problem: take in signals, decide, and pass a signal on. Compare the diagrams, then check the analogy table.

Neuron

Microcontroller

Dendrites receive input from other neurons≈Pins read voltage from sensors
A neuron only fires past a threshold voltage≈if (value > threshold) in your code
The axon carries one electrical signal onward≈A single output pin drives an LED or motor
Repeated firing strengthens a synapse (learning)≈Your code doesn't change itself — a program only does what you wrote
