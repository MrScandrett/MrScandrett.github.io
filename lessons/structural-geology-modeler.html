How This Model Is Built

Each glowing dot is a real data point — an interface contact or borehole hit. The colored surfaces in between are not measured directly: they are interpolated by fitting a smooth implicit function through the known points, the same "sparse data in, continuous 3D surface out" workflow that drives real subsurface modeling software (GemPy, Leapfrog, GeoModeller). Drag the cross-section slider to slice through the block and see the layers the way a geologist draws a cross-section.
