Web Studio

Build your website here first. Draw the layout, add behavior with blocks, polish the code, and share it on the class site. Then take the same files and publish them as your own website.

  1. Draw the layout
  2. Blocks add behavior
  3. Code polish the files
  4. Class site share it
  5. Your site publish it

Draw to code. Drag out boxes, text, images, buttons and links, then move and resize them like layers. Everything snaps to a 12-column CSS Grid, and every box is a grid too, so you can draw inside it. The canvas is drawn with the exact CSS you will get.

Sent. or .

Blocks build the same three files. Bring in your code (from a drawing or typed by hand) to see it as blocks, add events and actions, then send the blocks back to Code.

The real files. This is exactly what goes on the class site and on your own site. Edit, then watch the preview. Press Esc then Tab to leave the editor with the keyboard.

How Web Studio fits together

        

      • Code is the meeting point. Draw and Blocks each send their work to Code. Code can go back into Blocks; a drawing goes one way only, so keep drawing until the layout is right.
        • 

      • Nothing is silently overwritten. If you changed the code after the last send, the studio asks before replacing it. Save a project file whenever you want a safe copy.
        • 

      • Your work is saved in this browser, on this computer. Save project file makes a copy you can open anywhere, and it is the file you hand in.
        • 

      • Lessons that teach each part: HTML, CSS and Grid, JavaScript, testing, publishing.
