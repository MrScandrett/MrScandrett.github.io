Brendan Eich

Creator of JavaScript Netscape Communications, May 1995 Mocha · ECMAScript Co-founder of Mozilla & Firefox

Brendan Eich (born 1961) is the American computer programmer who created JavaScript in May 1995 in just ten intense days at Netscape Communications. Before JavaScript, the web was a collection of static, read-only documents: every single button press required reloading an entire page from a distant server. Eich gave browsers their own built-in programming language, transforming web browsers into universal operating systems capable of running interactive games, live searches, maps, and real-time simulations.

Who Is Brendan Eich?

Brendan Eich was born in Pittsburgh, Pennsylvania, on July 4, 1961. He studied mathematics and computer science at Santa Clara University and earned his master's degree in computer science from the University of Illinois at Urbana-Champaign in 1985. He spent a decade writing operating system kernels, network code, and microcode at Silicon Graphics (SGI) and MicroUnity Systems.

In April 1995, Marc Andreessen recruited Eich to join Netscape Communications in Mountain View, California. Netscape was preparing to release Netscape Navigator 2.0, the dominant web browser of the era. Sun Microsystems was heavily marketing Java as the programming language of the future, and Netscape had agreed to embed Java applets into Navigator. But Java was a heavyweight, strictly compiled, complex language aimed at enterprise computer scientists.

Andreessen and Eich realized the web needed a companion language: a lightweight, interpreted scripting language that amateur web creators, graphic designers, and novice scripters could type directly inside HTML. It needed to handle user interface events like button clicks, form validation, mouse hovers, and basic animations without having to compile code or run a whole Java virtual machine.

Working under a punishing deadline in May 1995, Eich designed and implemented the entire prototype in just ten days. Originally codenamed Mocha, it was briefly renamed LiveScript in September, and finally christened JavaScript in December 1995 as part of a marketing alliance with Sun. Despite being created so rapidly, Eich baked in sophisticated computer science concepts: first-class functions from Scheme and prototype-based object inheritance from Self, wrapped in the friendly curly-brace syntax of C and Java.

In 1998, Eich co-founded the Mozilla Project, helping open-source Netscape's browser code when Microsoft began bundling Internet Explorer with Windows. He served as Chief Architect, CTO, and CEO of Mozilla, creating the Firefox browser to ensure the web remained an open, standards-based public platform. In 2015, he founded Brave Software, pioneering privacy-first browsing and ad-blocking technologies.

  8. 2015 Oversees the historic ES6 release, adding arrow functions, promises, classes, and native modules.
  9. 2015 Founds Brave Software to build a privacy-first web browser with tracker blocking.

The 10-Day Sprint: How JavaScript Works

Before May 1995, if a user filled out an order form on the web and left out their zip code, the entire form had to travel over a slow telephone modem to a web server. The server checked the field, generated an error page, and sent it all the way back. Eich understood that code running right inside the browser could check the form in one millisecond, without a network request.

⚡
Event-Driven Execution

Programs do not wait in long loops; they listen for events like click, keydown, or load and react immediately.

🌳
The DOM (Document Object Model)

HTML elements become live JavaScript objects. Scripts can inspect, add, style, or remove any element on the page at runtime.

📦
First-Class Functions

Functions can be passed as arguments, assigned to variables, and returned from other functions (inspired by Scheme).

button.addEventListener("click", (e) => { ... });
button The DOM target element being monitored
"click" The event type dispatched by the browser engine
(e) => { ... } The callback function that runs in response to the user's action

This simple pattern underlies every interactive dropdown, video player, game loop, and dark mode toggle on the modern web.

Eich's Key Contributions

💻
JavaScript in 10 Days (1995)

Designed and built the working prototype of JavaScript for Netscape Navigator 2.0, giving the World Wide Web its programming language.

📜
ECMAScript Standardization

Brought JavaScript to Ecma International in 1996, creating the vendor-neutral ECMAScript standard that prevented Microsoft from creating an incompatible proprietary fork.

🦊
Mozilla & Firefox (1998–2014)

Co-founded the Mozilla Project, created the SpiderMonkey JS engine, and built Firefox to rescue the web from Internet Explorer's stagnating monopoly.

🚀
SpiderMonkey & JIT Compilers

Authored the original C/C++ engine for JavaScript, laying the foundation for modern Just-In-Time (JIT) compilation that allows JS to run at near-native C speed.

🧩
Functional Programming in Browsers

Insisted on first-class functions and closures, making JavaScript vastly more powerful than simple macro scripting languages of the 1990s.

🛡️
Privacy & Decentralization

Founded Brave Software to champion built-in privacy protection and shield users against pervasive online tracking and fingerprinting.

Eich's Legacy Today

When Brendan Eich wrote JavaScript in May 1995, critics scoffed that a language designed in ten days was just a toy for animated scrolling status bars and rollover buttons. Thirty years later, JavaScript is the lingua franca of world computing: it powers entire server fleets via Node.js, native mobile apps, desktop editors like Visual Studio Code, 3D games with WebGL, and machine learning models in TensorFlow.js.

By creating a language that was forgiving, accessible to beginners, and capable of growing through open standardization, Eich fulfilled the promise of Tim Berners-Lee's web: an open platform where anyone can write software and publish it directly to the planet without gatekeepers.

Practice Problems

Test your understanding of the origin of JavaScript, client-side events, and the open web.

Easy1. In approximately how many days did Brendan Eich write the initial prototype of JavaScript in May 1995?

Hint: It is one of the most famous sprints in computer history: exactly 10 days!

Easy2. At which company was Brendan Eich working when he created JavaScript?

Hint: The maker of Navigator, the browser that launched the dot-com era.

Medium3. What was the very first code name given to the language before it was renamed JavaScript?

Hint: Named after a famous type of coffee drink!

Medium4. Why was client-side execution inside the browser such a massive breakthrough compared to earlier websites?

Hint: Think about instantaneous feedback when typing into a search field or validating a form.

Medium5. What is the name of the official vendor-neutral standard specification that governs JavaScript?

Hint: Named after the European standards body Ecma International (ECMA-262).

Challenge6. Which open-source organization did Brendan Eich co-found in 1998 to protect the open web?

Hint: The creator of the Firefox browser!

Medium7. In JavaScript, what document representation turns HTML tags into live scriptable objects?

Hint: The tree-like object structure that represents HTML elements in memory.

Easy8. Are Java and JavaScript the exact same programming language?

Hint: As developers famously joke: "Java is to JavaScript as Car is to Carpet!"
