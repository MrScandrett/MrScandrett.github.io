Game Design & Development · Lesson 1

What Makes a Game?

Game Design MDA Framework Mechanics Dynamics Aesthetics Tiny-Loop Games

Before you write a single line of code, great games start with a clear design. Learn the four ingredients every game needs, the MDA framework designers use to think about play, and build your own game concept — no code required.

The 4 Ingredients of Every Game

Game designer Bernard Suits defined a game as "the voluntary attempt to overcome unnecessary obstacles." Every real game has four things:

🎯 Goals

A clear win or objective — reach the flag, score 10 points, survive the longest. Without a goal, there's no direction.

📋 Rules

Constraints that limit what you can do. Rules create the challenge — you can't just walk past the enemy, you have to jump over it.

📊 Feedback

Information that shows the player how they're doing — a score, a health bar, sound effects, screen shake. Feedback creates satisfaction.

🖐️ Voluntary Play

Players choose to play. This is what separates games from forced tasks. A truly fun game makes you want to keep playing.

Think About It: Take any game you know — Minecraft, tag, chess, or Mario. Can you name the goal, at least one rule, one form of feedback, and why people choose to play it?

The MDA Framework

Game researchers Robin Hunicke, Marc LeBlanc, and Robert Zubek created MDA in 2004 — the most widely used framework for understanding and designing games. It says every game can be analyzed at three levels:

⚙️ Mechanics The rules and actions written in code or on paper. "Press space to jump." These are what the designer controls directly.
→
🌀 Dynamics What actually happens when players interact with the mechanics. Jumping over enemies creates tension and timing puzzles — emergent behavior.
→
✨ Aesthetics The emotional response in the player — fun, excitement, challenge, curiosity, mastery. This is the real goal of game design.

Designers work top-down (decide the feeling first, design mechanics to produce it). Players experience games bottom-up (feel the mechanics, experience the dynamics, have the emotional response).

Super Mario Example: Mechanic — run and jump with momentum physics. Dynamic — timing jumps across gaps creates near-misses. Aesthetic — the thrill of skillful control and overcoming obstacles.

Tiny-Loop Games — Design Fast, Finish Strong

For a single-day build (a camp, a class period, a jam), the games that actually get finished are tiny-loop games: one mechanic, one win/lose condition, and one variable a student can customize. Big "adventure game" ideas explode in scope fast — a maze with an inventory and a boss fight is three unfinished projects wearing a trenchcoat. Start from one of the ten archetypes below instead of inventing a new genre from scratch.

The Tiny-Loop Test: Can you say your game idea in one sentence with exactly one verb? "Move to catch falling batteries" is a tiny loop. "Explore a world, collect items, upgrade gear, and defeat a boss" is not — that's four games glued together.
#1 Easiest
⭐Catch Game
Best: K–5 Scratch · MakeCode · Godot · Pygame

Kids understand it instantly — the safest pick for a one-day camp.

  • Move player left/right
  • Spawn falling objects
  • Good item touched → +1 score
  • Bad item touched → −1 life
e.g. Catch the Stars · Robot Collects Batteries · Frog Eats Flies
#2
💥Dodging Game
Best: 2nd–8th Scratch · MakeCode · Godot

Teaches collision, timing, and tension as difficulty ramps up.

  • Player movement
  • Enemy movement (chase, fall, or fly)
  • Collision = lose a life
  • Score/timer climbs while surviving
e.g. Dodge the Meteors · Don't Touch the Lava · Bee Avoids Birds
#3
🖱️Clicker Game
Best: K–6 Scratch · HTML/JS · MakeCode

Extremely easy to build — add an upgrade to make it feel like a real game.

  • Click/tap the sprite
  • Score increases
  • Upgrade makes score increase faster
e.g. Cookie Clicker · Gem Miner · Pizza Empire
#4
🧩Maze Game
Best: 3rd–8th Scratch · MakeCode · Godot

Great logic lesson — but hand out a maze template so drawing walls doesn't eat the whole day.

  • Arrow-key movement
  • Walls block or reset the player
  • Touch the goal tile to win
  • Optional: key/door mechanic
e.g. Escape the Lab · Mouse Gets Cheese · Knight Finds the Key
#5
🐦Flappy Clone
Best: 4th–8th Scratch · MakeCode · Godot

Very satisfying, but scrolling obstacles trip up true beginners — best once students know the basics.

  • Gravity pulls down
  • Key press = jump/flap impulse
  • Scrolling obstacles
  • Collision = game over
e.g. Flappy Bat · Rocket Through Asteroids · Dragon Through Towers
#6
🏓Pong / Paddle Game
Best: 4th–8th Scratch · MakeCode · Godot · Python

Teaches angles, velocity, and reflection — simplify the bounce math for younger kids.

  • Ball moves every frame
  • Bounces off walls and paddle
  • Score when the ball passes a side
e.g. Space Pong · Air Hockey · Magic Shield
#7
🫧Top-Down "Shooter"
Best: 4th–8th Scratch · MakeCode · Godot

Keep it nonviolent — pop balloons, clean trash, zap viruses, spray out fires.

  • Player movement
  • Projectile spawns and travels
  • Target disappears when hit
  • Score +1 per hit
e.g. Clean the Ocean · Wizard Shoots Spells · Firefighter Sprays Flames
#8
🎵Rhythm Tap Game
Best: 5th–12th Scratch · MakeCode · Godot

The coolest fit for a music/STEAM camp — but bring a starter engine so it finishes in a day.

  • Notes fall toward a target line
  • Press the matching key at the right time
  • Score is based on timing accuracy
e.g. Drum Hero · Piano Tap · Beat Bot
#9
❓Quiz Adventure
Best: K–6 Scratch · Slides · PowerPoint · Twine

Very easy and classroom-friendly — more design and writing than coding.

  • Question appears
  • Correct answer advances
  • Wrong answer gives a hint or a retry
e.g. Math Dungeon · Science Quest · Animal Rescue Quiz
#10
📖Choose-Your-Own-Adventure
Best: 2nd–8th Scratch · Twine · Slides · Canva

Best for mixed-ability teams — writers, artists, and coders can all contribute a piece.

  • Scene is presented
  • Player picks choice A or B
  • Each choice leads to a different outcome
e.g. Lost in Space · Forest Temple · Time Travel Lab
Strongest overall pick — "Robot Rescue" (Catch + Dodge hybrid): A robot collects batteries while avoiding water drops. Students customize the robot sprite, battery sprite, hazard sprite, background, score goal, speed, sound effects, and win message. Core loop: move left/right → battery falls (touch it, +1 score) → water falls (touch it, −1 life) → score 10 to win, 0 lives to lose. One design gives you programming, art, logic, debugging, and student personality — without letting the project sprawl.

Quick picks by grade band:

K–2Catch, Clicker, Quiz Adventure
3rd–5thCatch, Maze, Dodging
6th–8thFlappy Clone, Shooter, Pong
High SchoolRhythm, Platformer, Shooter, Godot Microgame

Game Design Document (Mini)

Identify the Elements

For each scenario, identify what game design element is being described.

1. In a racing game, a sound effect plays and the screen flashes green whenever you pass a checkpoint.

2. In chess, you cannot move your king onto a square that is under attack.

3. The objective of Pac-Man is to eat all the dots on the screen without being caught by a ghost.

4. A player quits a mobile game because it started feeling like homework — just chores to collect daily rewards.

Learning Goals

  • Name the 4 elements every game must have
  • Explain the MDA framework with an example
  • Identify game genre by its core mechanic
  • Match a project timeline to a tiny-loop archetype
  • Write a mini game design document

MDA Flow

Designers think M→D→A: choose a mechanic, predict what behavior emerges, aim for a target emotion. Players experience games in reverse: they feel the aesthetic first, before they understand the rules.

8 Aesthetic Types (LeBlanc)

  • Sensation — sight, sound, feel
  • Fantasy — make-believe worlds
  • Narrative — story and drama
  • Challenge — obstacle courses
  • Fellowship — co-op, social play
  • Discovery — exploration
  • Expression — self-customization
  • Submission — relaxing "flow state"

One-Day Camp Tip

For a single day, pick one of the ten tiny-loop archetypes instead of inventing a new genre. Scope kills unfinished student projects faster than bugs do.

Game Jam Tip

Write your GDD before you code. Even a half-page document with goal, mechanic, and one obstacle will save you hours of aimless building during a jam week.

Key Vocabulary

Mechanic
A specific rule or action available to the player (jump, shoot, drag, combine).
Dynamic
Emergent behavior that arises when players interact with the mechanics.
Aesthetic
The emotional response the game creates in the player.
GDD
Game Design Document — a written plan describing a game's concept, mechanics, and goals.
Emergent Gameplay
Unplanned, complex behaviors that arise from simple rules — like Minecraft's infinite possibilities from basic block placement.
Core Loop
The repeating cycle of actions that defines moment-to-moment play: shoot enemy → collect loot → upgrade weapon → shoot enemy.
Tiny-Loop Game
A game built around one mechanic, one win/lose condition, and one customizable variable — the format most likely to actually get finished in a single day.
Scope
The size and complexity of a project. Good game jam design starts small and well-scoped.
