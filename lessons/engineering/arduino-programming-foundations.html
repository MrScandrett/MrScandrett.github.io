Variables, Functions & Libraries

Blink hard-codes everything. Real sketches store readings in variables, turn repeated steps into functions you can call by name, and borrow other people's tested code with a single #include line instead of reinventing it.

  brightness = scaleReading(lightLevel);

Storing information

Variables & data types

A variable is a named box that holds a value your sketch can read and change. Every variable in C++ (the language Arduino sketches are written in) needs a data type that says what kind of value it can hold.

TypeHoldsExample
intWhole numbers, roughly ±32,000int pin = 9;
floatDecimal numbersfloat tempC = 21.5;
booltrue / false onlybool isPressed = false;
charA single characterchar grade = 'A';

Reading the analog world

analogRead() and map()

A sensor's raw reading rarely matches the range you want to use it in. analogRead() returns a value from 0 to 1023; analogWrite() (PWM brightness) expects 0 to 255. map() rescales one range into another. Drag the slider to simulate a light sensor and watch both numbers — and the LED — update.

Reusable steps

Writing your own function

A function packages a sequence of steps under one name. scaleReading(raw) takes a parameter (an input value named raw) and returns a result — so loop() can call it instead of repeating the math every time. Press run to trace which code actually executes when loop() calls the function.

loop()

void loop() {
  lightLevel = analogRead(A0);
  brightness =
    scaleReading(lightLevel);
  analogWrite(9, brightness);
}

  return map(raw,

Don't reinvent the wheel

Libraries: borrowing tested code

A library is someone else's code, packaged so you can use it with one line — #include <LibraryName.h> — instead of writing the low-level details yourself. Three you'll meet constantly:

<Servo.h>

Turns a few lines of manual pulse-timing into myServo.write(90); — set an angle and go.

<Wire.h>

Handles the I2C protocol so two-wire sensors and displays can be addressed by a simple ID number.

<DHT.h>

Decodes a temperature/humidity sensor's raw timing signal into clean °C and % values.

Libraries are installed once (Library Manager) and included once per sketch — but which board you've selected can still matter, since some libraries only work with certain chips (a Wi-Fi library for the ESP32 won't run on an Uno).
