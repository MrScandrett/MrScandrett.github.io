Use the labels

What should this wire connect to?

Practice on a UNO R3. A pin number is an address for your code, not a voltage. D9 means digital pin 9; A0 means analog input 0. One physical pin can have several jobs, but your circuit must choose compatible uses.

Power · 5V / 3V3 / GND

Supply energy and provide the common reference. VIN is an input before regulation, not a digital pin.

Signals · D / A / ~

D reads or writes HIGH/LOW. A measures voltage. ~ adds PWM output: fast HIGH/LOW pulses, not a smooth analog voltage.

Communication · TX/RX / SDA/SCL

These carry messages. On the UNO R3, A4/SDA and A5/SCL are shared functions, not extra independent pins.



Plan before wiring: name the signal, select a pin, check the component’s supply and logic voltages, and include the return path. A GPIO sends a control signal; a motor needs a driver and a suitable power source.

Same language, different hardware
From one brain to two

            
Every board in the menu above runs the same setup() / loop() sketch structure and the same core functions — pinMode(), digitalWrite(), analogRead(). What actually differs board to board is the hardware you're programming: the number of usable pins, how much sketch memory you get, whether the chip talks to Wi-Fi or Bluetooth on its own, and whether its pins run at 5 volts or 3.3 volts. The sketch structure is familiar, but pin mappings, libraries, USB behavior, and timing may require code changes. On UNO Q, Arduino sketches run on the MCU; Linux applications run separately on the MPU.

The gotcha
5 volts vs. 3.3 volts

            
The Uno, Nano, Mega, and Leonardo all read and write pins at 5V. The ESP32 and ESP8266 read and write pins at 3.3V — and their pins are not tolerant of 5V. Check the exact board and sensor specifications before joining their signals.

            

              
5V family
UNO R3 · classic Nano · Nano Every · Mega · Leonardo/Micro · UNO R4 GPIO. A driven HIGH output is near the board’s logic supply; input thresholds are specified separately. Most beginner sensor modules and shields are designed around this voltage.

              
3.3V family
ESP32 · ESP8266 · UNO Q MCU GPIO. Not every board named Nano uses 5V logic. A driven HIGH output is near 3.3V; input thresholds are specified separately. Feeding a 5V sensor's output straight into one of these pins can damage the chip.

            

            
Rule of thumb: before wiring a 5V-family sensor to an ESP32 or ESP8266, add a voltage divider or logic-level converter between them — never connect the 5V output pin directly to a 3.3V input pin.

            Materials
            
Core kitNo hardware required — this is a planning/reasoning lesson best run before students select boards for a project. A mixed set of physical boards to pass around reinforces the size/pin-count differences well.

            
Launch question"If Blink runs on every board here, what's actually different between them?" (Pins, memory, voltage, wireless — not the code.)

            
ExtensionHave students research one additional board not covered here (e.g. Arduino Due, Teensy, Raspberry Pi Pico) and add a row to the comparison table.

            
AssessmentA short written justification: given a project brief, name a board and cite two spec-table facts that justify the choice.

            
SafetyIf handling real ESP32/ESP8266 boards alongside 5V-family boards, flag the voltage difference before any wiring — this is the single most common way students damage a board.
