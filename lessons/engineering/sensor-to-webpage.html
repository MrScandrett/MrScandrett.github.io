Sensor to Webpage

Newton had to compute orbits with pen and paper. You're going to make a hidden physical quantity — light, temperature, distance — show up live on a screen in about twenty minutes. Read a sensor, print it to Serial, then let a simple webpage read that same stream and display it as it changes.

Core idea

Voltage is invisible until you print it

A sensor turns a physical quantity — light level, temperature, distance — into a voltage between 0V and 5V. Arduino's analogRead() converts that voltage into a number from 0 to 1023. On its own, that number lives only inside the chip. The build below makes it visible in two places at once: the Serial Monitor, and a webpage running in a browser on the same computer.

Step 1 — wire it up

Sensor into an analog pin

Any analog sensor works the same way here: a photoresistor (LDR), a potentiometer, or a temperature sensor like a TMP36 all output a variable voltage that A0 can read. Wire the sensor's signal leg to A0, power to 5V, and ground to GND.

const int sensorPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int reading = analogRead(sensorPin);
  Serial.println(reading);
  delay(200);
}

// reading is 0-1023: 0 = 0V, 1023 = 5V
// one line of text per reading, ~5 per second

Step 2 — read it in the browser

Web Serial: the same stream, on a webpage

Chrome and Edge can talk directly to a USB serial port from JavaScript using the Web Serial API — no server, no extra software. The page below asks the user to pick the Arduino's port once, then reads whatever Serial.println() sends and updates the display every time a new line arrives.

<button id="connect">Connect to Arduino</button>
<div id="value">--</div>

<script>
connect.addEventListener('click', async () => {
  const port = await navigator.serial.requestPort();
  await port.open({ baudRate: 9600 });

  const reader = port.readable
    .pipeThrough(new TextDecoderStream())
    .pipeThrough(new TransformStream(new LineBreakTransformer()))
    .getReader();

  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    value.textContent = value.trim(); // update the page
  }
});
</script>

That's the whole loop: request the port once, then read lines forever. Everything else — turning that number into a bar graph, a color, or a gauge — is just regular HTML/CSS/JS reacting to a variable that now updates five times a second from the real world.

Materials
Core kitOne Arduino Uno (or compatible board) and one analog sensor (photoresistor, potentiometer, or TMP36) per pair, plus a Chrome or Edge browser.
Launch question"NASA engineers used to need a whole lab to display a live sensor reading. What's stopping you from doing it on a $30 board in twenty minutes?"
Web Serial noteRequires Chrome or Edge (not Safari or Firefox) and a page served over HTTPS or from localhost — a plain double-clicked HTML file won't have permission to request a port in some setups, so serve it with a simple local server if requestPort() fails silently.
Common snagIf the browser can't see the port, the Serial Monitor in the Arduino IDE is probably still holding it open — close the IDE's Serial Monitor before connecting from the page.
AssessmentA working circuit that prints changing sensor values to Serial, plus a webpage that connects over Web Serial and visibly updates as the sensor changes.
SafetyLow-voltage USB power only.
