ALIGN

Respect direction

Keep wood grain, cloth weave, panels, and bricks oriented consistently.

SPLIT

Match shading

A hard shading edge commonly needs a UV split; test checker distortion before painting.

02 / PACK

Use pixels fairly

Match texel density before packing.

  1. Apply object scale.UV calculations inherit hidden scale problems.
  2. Mark seams and unwrap.Use a checker texture with numbered squares to expose stretching and rotation.
  3. Normalize island scale.Two similarly important surfaces should show similarly sized checker squares in 3D.
  4. Prioritize visible surfaces.Large or close hero faces may receive more UV area; hidden bottoms can receive less.
  5. Pack with padding.Leave enough space between islands to prevent color bleeding at lower mip levels.
Do not chase 100% fill.Readable orientation, consistent density, safe padding, and easy editing are more valuable than squeezing every last empty pixel.

04 / EXPORT

GLB handoff

Freeze the contract before export.

  1. Save the source file.Export is a deliverable, never a replacement for the editable .blend.
  2. Name objects and materials.Names should describe role and variation, not the order in which Blender created them.
  3. Apply transforms and inspect normals.Keep intentional origins. Remove disabled experiments and stray objects.
  4. Export glTF 2.0 as GLB.Export selected objects when appropriate; include materials and required animation only.
  5. Place the GLB in the Godot project.Use the Import dock and advanced import settings when extraction or overrides are needed.
