01

UVs

Unfold the surface

A UV map tells a texture where to sit.

Every mesh face needs a matching 2D location in a flat "UV" layout before an image texture can wrap around it correctly. Think of it like unfolding a cardboard box flat before printing a design on it.

  1. Mark seams

    In Edit Mode, select edges where the unfold should split — like the inside seam of a sleeve — and press Ctrl+E → Mark Seam.

    Ctrl+E
  2. Unwrap

    Select all (A) and press U → Unwrap. Open a UV Editing workspace tab to see the flattened result.

    U
  3. Create a checker

    UV Editor header → Image → New → Generated Type → UV Grid, then confirm. Even squares mean a healthy unwrap; stretched squares mean the seams need adjusting.

    Checker check
Simple objects need few seamsA cube-like prop might only need seams where a real object would have real edges — a wrench doesn't need to be cut into a dozen pieces to unfold cleanly.
02

Material

One node covers most materials

Meet the Principled BSDF.

Create one at Properties Editor → Material Properties (red sphere) → New, then open the Shading workspace. The new material starts with a Principled BSDF node.

●

The color

Base Color

The surface's raw color, or an Image Texture node plugged into this input.

◐

Shiny vs. matte

Roughness

0 is a mirror, 1 is chalk-matte. Most real-world materials sit between 0.3 and 0.7.

◆

Metal or not

Metallic

0 for wood, fabric, or plastic. 1 for bare metal. Rarely anything in between.

Add an image texture

Shading workspace → Shader Editor → Shift+A → Texture → Image Texture Load an image, then connect Color to the Principled BSDF's Base Color.

03

Paint

Straight onto the pixels

Paint marks directly onto the texture with a brush.

An Image Texture node holds pixel data like any picture file. Texture Paint mode lets you paint straight onto it in the 3D Viewport with a brush, instead of round-tripping through an external image editor — good for grime, scratches, and hand-placed detail a plain image alone won't give you.

  1. Mark the target image active

    In the Shading workspace's Shader Editor, click your Image Texture node once so it's outlined white. Texture Paint always paints onto whichever Image Texture node is currently active.

    Active node
  2. Enter Texture Paint mode

    Open the Texture Paint workspace tab, or use the mode dropdown. You need real UVs first (section 01) — Blender uses them to know where a brush stroke lands on the flat image.

    Texture Paint
  3. Pick a brush and paint

    Draw lays down flat color; Soften and Smear blend pixels that are already there instead of adding new ones. Adjust Radius and Strength with F and Shift+F — the same pattern as sculpt brushes.

    F
Save the paint, not just the fileA painted image lives only in memory until you save it on its own: with the image open in an Image Editor, use Image → Save As, or pack it into the .blend with top menu → File → External Data → Pack Resources. Ctrl+S alone does not save an unpacked image's pixels.
04

Blend

One weight, painted by hand

Blend two textures with a mask you paint on the mesh.

A single Image Texture is one material across the whole surface, but real ground never is — sand near a path, grass in the middle, bare stone at the edges. Instead of painting that transition in an image editor, paint it directly on the mesh as a Vertex Group weight, then read that weight back in the Shader Editor to mix between two Image Texture nodes.

  1. Add a vertex group

    Object Data Properties (green triangle icon) → Vertex Groups → +, then name it something you'll remember — Blend works. Enter Weight Paint mode from the workspace tab or the mode dropdown.

    Vertex Groups
  2. Paint the heat map

    Paint with the Draw brush: full Weight (red) marks one texture, zero weight (blue) marks the other, with the green-to-yellow middle blending between them. Set the brush's Weight value in the tool settings before each stroke.

    Weight Paint
  3. Read it into the shader

    Back in the Shading workspace: Shader Editor → Shift+A → Input → Attribute, set its Type to Geometry, and type your vertex group's exact name into the Name field — it won't appear in a dropdown, so a typo here silently reads nothing.

    Attribute
  4. Mix the two textures

    Shift+A → Color → Mix Color. Plug your two Image Texture nodes into A and B, and the Attribute node's Fac output into the Mix node's Factor. The Mix output goes to the Principled BSDF's Base Color.

    Mix Color
Sharpen the transition with a Color Ramp

A raw painted weight blends softly. For a harder edge, route the Attribute's Fac through Shift+A → Converter → Color Ramp first, then feed the ramp's output into the Mix node's Factor instead. Drag the ramp's triangular stop markers together to sharpen the blend, or apart to soften it — no repainting required.

Adding a third textureChain a second Mix Color node off the first one's output, add a Stone texture as its B input, and drive its Factor from a second vertex group (or a second Color Ramp reading the same one) so stone only appears at the highest weights.
05

Light

Direction sells the shape

Light like a photographer, not a floodlight.

One light straight-on flattens a form. A simple three-point setup reads as intentional: a strong key light, a softer fill from the opposite side, and an optional rim light to separate the subject from its background.

1

Key

Your main light, angled 30–45° from the camera. This defines the primary shadows.

2

Fill

A dimmer light from the opposite side, softening the shadows the key light creates.

3

Rim

A light from behind the subject, catching its edge to separate it from the background.

The World also lights your sceneProperties Editor → World Properties (globe) → Surface → Background → Strength Raise it slightly for a quick, even base light.
06

Render

Turn the scene into an image

Choose an engine, then press F12.

Properties Editor → Render Properties (camera) → Render Engine → EEVEE or Cycles

⚡

Fast, real-time

EEVEE

Rasterized rendering — near-instant feedback, great for classroom iteration and game-style lighting.

◑

Slower, physically accurate

Cycles

Path-traced light simulation — more realistic reflections and shadows, at a real time cost per image.

  1. Position the camera

    Numpad 0 views the active camera. To snap it to your current view once, use Ctrl+Alt+Numpad 0. To keep adjusting the shot by orbiting the viewport itself, open the Sidebar (N) → View tab → Lock Camera to View checkbox instead — every viewport move drags the camera with it until you turn it back off.

    Camera
  2. Render

    Press F12, or use top menu → Render → Render Image. Blender opens the Render Result in the Image Editor.

    F12
  3. Save the image

    In the Image Viewer, Image → Save As, and choose PNG for a lossless result.

    Save As
07

Build

Hands on

Finish and render one object.

  1. Choose an object

    Your Lesson 03 chair or Lesson 06 tool works well — something with a few clear surfaces.

    Choose
  2. Mark seams and unwrap

    Mark seams, use U → Unwrap, then create the checker at UV Editor → Image → New → Generated Type → UV Grid.

    UVs
  3. Build a material

    Set Base Color, Roughness, and Metallic to match the real material — wood, painted metal, or plastic.

    Material
  4. Light it

    Add a key and fill light, and raise the World strength slightly.

    Light
  5. Frame, render, save

    Position the camera, press F12, and save the result as a PNG next to your .blend file.

    Render
The render looks black, or the texture isn't showing?
  • In the 3D Viewport press Z → Material Preview or Rendered; Solid mode ignores image materials.
  • Confirm the Image Texture node's Color output is connected to Base Color.
  • Check World Properties → Surface → Background → Strength and at least one light's Object Data Properties → Light → Power are above zero.

Key vocabulary

UV map
A flat 2D layout of a mesh's surface, used to place textures.
Seam
A marked edge where the UV unwrap splits the mesh open.
Principled BSDF
Blender's all-purpose physically based material node.
Texture Paint
A mode that paints pixels directly onto an image texture with a brush.
Vertex Group
A named, per-vertex weight (0 to 1) painted onto a mesh.
Attribute node
Reads a named mesh attribute, like a vertex group, into the shader.
Color Ramp
Remaps a value through a gradient using draggable color stops.
Lock Camera to View
A toggle that drags the camera along with every viewport move.
EEVEE
Blender's fast, real-time render engine.
Cycles
Blender's slower, physically accurate path-traced render engine.
