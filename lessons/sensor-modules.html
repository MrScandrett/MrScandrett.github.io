Kit Overview

This style of sensor kit is popular because it gives beginners a large variety of modules at a relatively low cost. It works well as an introduction to physical computing because each board usually exposes a simple set of pins for power, ground, and signal.

Compatibility Note The kit is commonly used with Arduino-style boards and is also compatible with STM32 hardware in principle, but STM32 wiring and software support may require separate tutorials and examples.
Power Warning The Elegoo power supply module expects 6.5V to 9V DC through a 5.5 mm × 2.1 mm plug. Do not exceed that range, or you risk damaging the board and other chips connected to it.
What is included The kit provides sensor and interface modules only. You still need jumper wires and a controller board to actually use them.
Best use case Quick labs where students compare many sensing methods without soldering separate circuits from raw parts.
What to learn first Always identify whether a module is an input sensor, an output device, or an interface board before wiring it.

How To Think About Sensor Modules

Not every board in a sensor kit is actually a sensor. Some are inputs that measure the world, some are outputs that create light or sound, and some are support modules that handle display, power, or communication.

Type What It Does Examples From This Kit
Environmental / Physical Input Measures light, motion, sound, temperature, humidity, water, or magnetic effects Photo-resistor, PIR, flame, hall, sound, DS18B20, DHT-style temperature-humidity, water level
User Input Lets a person control the circuit directly Joystick, button, rotary encoder, membrane switch, metal touch, tap, tilt switch
Output / Alert Creates sound, light, switching, or signaling RGB LED, SMD RGB, two-tone LED, 7-color flash, laser emitter, buzzers, relay
Timing / Interface / Support Helps the system keep time, communicate, or power other modules RTC module, IR receiver/emitter, LCD1602, power supply, GY-521 motion board

Starter Project Ideas

These pairings help students see how different modules can work together.

Motion Alarm Use the PIR sensor with an active buzzer and RGB LED to create a simple room monitor.
Light Meter Use the photo-resistor and LCD1602 to display changing light values in real time.
Digital Thermometer Pair the DS18B20 or temperature module with the LCD display for a live readout.
Distance Warning System Combine the ultrasonic module with LEDs or a passive buzzer that changes pitch as an object gets closer.
Door Open Detector Use the magnetic spring module to sense when a magnet moves away from the frame.
Remote-Control Demo Use the IR receiver and emitter modules to explore line-of-sight communication.

Common Beginner Mistakes

Forgetting the controller board This kit does not run by itself. Every module needs a microcontroller and jumper wires.
Mixing analog and digital expectations Some modules output a changing analog value, while others simply report HIGH or LOW.
Overpowering the supply board Stay within the specified 6.5V to 9V DC range for the dedicated power module.
Assuming every board is a sensor Relay, LCD, and buzzers are useful modules, but they are outputs or interface boards rather than sensors.
Skipping pin labels Check each module for power, ground, digital, analog, or special communication pins before wiring.
Expecting STM32 instructions in-kit The kit may physically work with STM32 boards, but classroom examples are often written for Arduino first.
