Studio protocol

Learn with Blender open.

Reading or watching can make a tool feel familiar without making it usable. Every tutorial in this pathway follows the same four-beat studio loop.

  1. LOOKRead one move

    Find the menu path, shortcut, and picture for one small step.

  2. DOMake it in Blender

    Switch windows and perform the move before reading ahead.

  3. CHECKCompare the evidence

    Match the silhouette, dimensions, Outliner, or modifier settings shown.

  4. REPAIRDiagnose one difference

    Use the rescue notes; undo only to the last working version.

Four habits that save every project

Save incrementally

Ctrl+S after every working step. Use Ctrl+Shift+S to save a new numbered version before a risky change.

Name everything

Double-click objects and collections in the Outliner to rename them. "Cube.004" six layers deep will cost you ten minutes later.

Model at real scale

Keep Blender's default unit as 1 meter and build to real-world dimensions. Scale mistakes compound the moment you add a second object.

Apply before you ship

Modifiers and transforms stay editable until you apply them. Apply scale and rotation (Ctrl+A) before exporting or rigging.

Folder rule

Keep one project folder per lesson: blender-lessons/01-interface/, 02-windows-doors/, and so on. Save reference images inside an reference/ subfolder so relinking never breaks.

Use human-made, public-domain starter assets

The pathway does not use generated texture, skybox, or model files. Its imported classroom character is already CC0, and its Blender screenshots are authentic captures from official documentation. For new project assets, start with these verified CC0 libraries instead of generated imagery.

CC0 · HUMAN-MADEPoly Haven

Photoscanned PBR textures, photographic HDRIs for world lighting and skyboxes, and production-ready 3D models. Poly Haven explicitly excludes generative AI from asset creation.

 CC0 · GAME READYQuaternius

Stylized characters, animation libraries, props, vehicles, and environment kits in Blender- and engine-friendly formats.

 CC0 · CLASSROOM FRIENDLYKenney game assets

Large collections of clear, lightweight 2D and 3D game assets. Every asset-page download is public-domain licensed.
Source contract for every downloaded asset
  • Save the original asset-page URL and exact asset name.
  • Record CC0 or public-domain status beside the file.
  • Keep the original license file when a download includes one.
  • Do not use an asset when its creator, license, or generation method is unclear.
