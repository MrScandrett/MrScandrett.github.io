04

Build

Hands on

Assemble your first 3D room.

  1. Create the root

    Choose 3D Scene. Rename the root Main, then save it as main.tscn.

    Node3D
  2. Add a floor

    Add StaticBody3D. Give it a MeshInstance3D with a BoxMesh and a CollisionShape3D with a BoxShape3D. Scale it wide and flat.

    Doesn't move
  3. Add the player

    Add CharacterBody3D, rename it Player, then add a MeshInstance3D and CollisionShape3D beneath it. Move Player above the floor.

    Moves by code
  4. Light the room

    Add DirectionalLight3D. Rotate it until you can see shadows and shape.

    Makes form visible
  5. Frame the action

    Add Camera3D. Move it back and up, angle it toward the room, and make sure Current is enabled.

    What the player sees
Nothing appears when you press Play?
  • Confirm Camera3D is marked Current.
  • Check that the camera points toward the floor and player.
  • Make sure your MeshInstance3D nodes have an actual mesh assigned.
  • When asked for a main scene, choose main.tscn.
05

Script

Make it move

Map intentions, then write movement.

Open Project → Project Settings → Input Map. Add four actions and bind the keys shown. Action names keep your code readable and make gamepads easier to add later.

Wmove_forwardSmove_backAmove_leftDmove_right

Attach a new script named player.gd to the Player node. Replace its contents with:

player.gd
extends CharacterBody3D

@export var speed := 5.0

func _physics_process(delta):
    var input := Input.get_vector(
        "move_left", "move_right",
        "move_forward", "move_back"
    )
    var direction := Vector3(input.x, 0, input.y)

    velocity.x = direction.x * speed
    velocity.z = direction.z * speed

    if not is_on_floor():
        velocity.y -= 9.8 * delta

    move_and_slide()

Input.get_vector() combines four named actions into one 2D direction. Pressing opposite keys cancels out.

06

Play

Test the idea here

Use WASD to cross the room.

GOAL

Click the room, then use WASD.

Player falls forever

The floor or player is missing a CollisionShape3D, or the shapes do not touch.

Keys do nothing

Check Input Map spelling. Action names must exactly match the strings in the script.

Player passes through floor

Make sure the floor's collision shape is a child of StaticBody3D.

Red error appears

Read the first red line in the Debugger. It usually points closest to the cause.

Key vocabulary

Node
One object with one main job.
Scene
A saved tree of nodes that can be reused.
Root
The top node in a scene.
Child
A node nested beneath another node.
Instance
A reusable copy of a saved scene.
Signal
A message emitted when an event happens.
GDScript
Godot's built-in scripting language.
Collision shape
An invisible boundary used by physics.
