First project

Make a desk helper

Design something that holds one school item: a pencil, a note, a book, or a phone. Your object needs a stable base and an opening, slot, or raised edge that does the holding.

See the item, opening, and base together

This pencil helper is one possible answer. Its dimensions are examples: measure the item in your classroom, make a quick version, then change what the test reveals.

  1. NoticeWhat must your object hold? How big is it?
  2. PlanSketch the front and top. Mark one size or measurement.
  3. MakeJoin shapes or remove a shape to create the holder.
  4. TestTry the real item or inspect the model from three views. Change one feature and explain why.

K–2 · Make and describe

Build a model with blocks, cardboard, or clay. Point to the base and the part that holds the item. Turn it and draw what you see from above. An adult can demonstrate the same shapes in Workbench.

Show: your model and a drawing; say what you changed after the item slipped or tipped.

Grades 3–5 · Shape and measure

Measure your item with a ruler. Sketch a base, then make a digital version with two or more shapes in Workbench. Use the camera to check the opening. Save the editable project with adult help if needed.

Show: a top view, one measurement, and a before/after change.

Grades 6–8 · Model and compare

Draw aligned views in Blueprint Drafting Studio. Build the design in Workbench or Forge, then compare its dimensions with the plan. Test a physical prototype or ask a teacher to review a slicer preview.

Show: the plan, editable model, and evidence from a test.

Grades 9–12 · Engineer and iterate

Set measurable limits for size and stability. Model with dimensions, inspect a mesh export, and revise after a user test. If printing, justify orientation, contact area, supports, and clearance using a slicer preview.

Show: a design file, export, test result, and reasoned revision.

Class checkpoint: Can a partner identify what the object holds, find the feature that holds it, and name the change that made it work better?

Shared skills

Learn to see and change a model

Do these three short practices when you are ready for digital modeling. Use the same object each time. Teachers can demonstrate a step for younger students before they try it.

  1. Navigate a 3D view

    Orbit, pan, zoom, and show the front, side, and top. Check that the object has not moved when the camera moves.

  2. Move and resize a shape

    Translate, rotate, scale, name, and save a simple model. Reopen it to prove the editable file is usable.

  3. Make an opening

    Use a second shape to cut a real opening. Explain which shape adds material and which removes it.

Ready for a route: Show three views, one measurement, one change to the shape, and a reopened model.

Physical objects

Make it real

Design a measured object, inspect its export, and plan a print. A printer is optional: a slicer preview and a proposed test count as planning evidence.

  1. Plan in 2D

    Draw aligned views and dimensions that another maker could use.

  2. Build in Forge

    Save an editable model and export an STL. Check a known dimension after import.

  3. Prepare the print

    Compare orientations, support needs, and bed contact in the slicer. Use the teacher-approved printer and material profile.

  4. Extend to moving parts

    Print a clearance test before designing a fidget that moves.

Finish when: The imported size matches your plan and you can explain a print decision using a preview or test result.

Printer handoff: A teacher runs the printer and handles its hot nozzle, heated bed, tools, and finished part until it cools. Students prepare and discuss the design, then follow classroom equipment rules.

Models and images

Make it look

Develop one model and present it clearly. Use the browser workshops first; the Blender instructions are deeper reference.

  1. Model a character

    Build a readable silhouette. For a hard surface object, use the props workshop instead.

  2. Refine the form

    Save a copy before changing the mesh. Compare the shape before and after.

  3. Present the same model

    Choose materials, camera, and light; render an image that makes the form easy to read.

Finish when: Your editable model reopens and you can explain one shape choice and one presentation choice.

Game-ready objects

Make it play

Build reusable objects that fit a game world, then test the export in its destination. Game Asset Studio has the full project briefs.

  1. Create textures

    Make a small material set with a consistent visual style.

  2. Build a prop

    Reuse a chair or other object you already modeled.

  3. Assemble a room

    Use a grid and repeatable dimensions.

  4. Export and test

    Check UVs, materials, scale, and pivots in the destination engine.

Finish when: The exported kit assembles correctly outside the modeling app. Record whether engine testing is complete.

Extend into character animation
  1. Rig your character and check bends.
  2. Animate named actions and test each loop.
  3. Use the asset in Godot.

Show your thinking

Keep a small design record

  1. Plan: Name the user, purpose, and one requirement you can check.
  2. Build: Save an editable file or photograph a physical model.
  3. Test: Try the real item, inspect the slicer, or open the export in its destination.
  4. Improve: Show the earlier version and explain one change.

Teachers can accept spoken explanations and photographed models for younger students. Older students should include measurements, files, and evidence from testing.
