Workspace

A node graph for the finished image

The Compositing tab works after the render, not before it.

Click the Compositing tab. If the node graph is empty, the header's Use Nodes checkbox turns it on — Blender starts you with a default Render Layers node already wired to a Composite node.

This graph runs on every renderOnce built, the compositing graph applies automatically every time you press F12 — you're not manually reprocessing each image by hand.
02

Layers & Viewer

Three nodes you'll always have

Render Layers in, Composite out, Viewer to check your work.

◧

The input

Render Layers

The rendered image and its passes — Alpha, Z-depth, and any Cryptomatte mattes you enabled in Render Properties.

◨

The final output

Composite

Whatever reaches this node is what gets saved when you render — this is the graph's actual destination.

◉

A free preview

Viewer

Connect any node to a Viewer to preview it in the image area, without changing what Composite outputs.

  1. Add a Viewer

    Shift+A → Output → Viewer, or hold Ctrl+Shift and click any node to wire a Viewer to it instantly.

    Ctrl+Shift+Click
  2. Toggle the backdrop

    The node editor's Backdrop toggle in the header shows the Viewer's current image behind the nodes themselves.

    Backdrop
03

Common nodes

A small toolkit covers most grading

Four nodes handle almost every finishing pass.

◐

Color grade

Color Balance

Pushes shadows, midtones, and highlights toward different colors — the same lift/gamma/gain grading photographers use.

✦

Bright-area glow

Glare

Adds bloom, streaks, or a fog glow around the brightest parts of a render — Fog Glow is the most forgiving starting mode.

▢

Soften

Blur

Softens an image or a single channel — useful for depth-of-field effects driven by the Z-depth pass.

▣

Layer two images

Alpha Over

Composites one image over another using alpha transparency — a logo over a render, or two separate renders combined.

04

Build

Hands on

Grade a render you already made.

  1. Render a scene

    Use the lit, materialed object from Materials, Lighting & Render, or any scene with a camera and at least one light. Press F12.

    F12
  2. Open Compositing and enable nodes

    Click the Compositing tab; turn on Use Nodes if the graph is empty.

    Use Nodes
  3. Add Glare

    Shift+A → Filter → Glare, wired between Render Layers and Composite. Set Glare Type to Fog Glow and lower Threshold until only the brightest areas bloom.

    Glare
  4. Add Color Balance

    Shift+A → Color → Color Balance, after Glare in the chain. Nudge Gain slightly toward one color for a deliberate mood.

    Color Balance
  5. Preview, then render again

    Wire a Viewer to the end of the chain to confirm the look, then press F12 — the graded version is what saves now.

    Re-render
  6. Save as a second file

    Image → Save As in the Image Editor, with a filename that makes clear this is the graded version.

    Save As
The image didn't change after adding nodes?
  • Check Use Nodes is actually on — an unchecked box means the graph is built but ignored.
  • Confirm the chain reaches Composite, not just a Viewer — Viewer previews without affecting the saved render.
  • Press F12 again after editing the graph; the Image Editor doesn't re-run the graph on an old render automatically.

Learning goals

  • Explain why the Compositor runs after the render, not before
  • Use Render Layers, Composite, and Viewer nodes together
  • Apply Glare and Color Balance to grade an image
  • Preview a mid-graph result without changing the saved render
  • Re-render and save a graded image separately from the original

Requires

  • Materials, Lighting & Render (or any lit, rendered scene)

Save habit

Save the graded image under a new filename. Overwriting the original render makes it impossible to compare before and after.

Key vocabulary

Compositor
Blender's node editor for processing a rendered image after it's produced.
Render Layers node
The compositor's input — the rendered image and its passes.
Composite node
The compositor's final output; whatever reaches it is what gets saved.
Viewer node
Lets you preview any point in the graph without affecting the saved render.
Glare
A node that adds bloom, streaks, or glow around bright areas.
