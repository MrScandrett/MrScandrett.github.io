Lesson 02 · 70 minutes · Prop modeling

Model the shape players recognize.

Build a chair, desk, side table, shelf, or stool from measured forms. Spend geometry on silhouette and shading, not on details the player will never see.

01 / PLAN

Reference and scale

Write a tiny asset brief before opening Blender.

Player readsWhat function and mood should the prop communicate from several meters away?
DimensionsRecord width × depth × height in meters from a real example.
CameraWill players inspect it closely, see it in the background, or both?
ReuseWhich parts can be mirrored, instanced, or reused on another prop?
BudgetSet a classroom target such as 500–3,000 triangles, then justify exceptions.
Coordinate agreement: Model upright with Z as up in Blender. One Blender meter should become one Godot meter. Keep the object near the world origin.
02 / BLOCK

Large forms first

Prove the silhouette with boxes.

  1. Add a human-scale reference.Use a 1.7–1.8 m guide or measured cube so the prop cannot quietly become giant.
  2. Block the largest masses.For a chair: seat, back, then legs. Use orthographic front and side views.
  3. Check negative space.The gaps between legs and under the seat are part of the silhouette.
  4. Duplicate repeated parts.Use linked duplicates or a Mirror modifier while the design is still changing.
  5. Orbit from game distance.If the prop only reads in close-up, strengthen proportions before adding detail.

03 / FINISH

Shading without waste

Bevel real edges and control normals.

BEVEL

Edges catch light

Use a small, consistent bevel. Two or three segments are often enough for a game prop.

NORMALS

Faces shade cleanly

Shade Auto Smooth or use appropriate normals so flat panels remain flat while bevels appear rounded.

TOPOLOGY

Edges have a job

Keep edges that change silhouette, support shading, define UV seams, or enable deformation.

DETAIL

Tell a scale story

Add one or two functional details: joinery, drawer gap, cushion seam, handle, or fastener.

Bevel looks uneven? In Object Mode, apply scale before judging bevel width. Non-applied scale is a frequent cause of stretched bevels and export surprises.
04 / PIVOT

Engine behavior

Place the origin where the object behaves.

A static chair can use an origin centered on the floor footprint. A door needs its origin on the hinge. A drawer needs it centered along the slide. Name the mesh for another human: SM_Chair_Studio_A, not Cube.017.

05 / TEST

Game-ready check

Export the prop, then distrust your memory.

  1. Apply rotation and scale.Confirm dimensions again after Ctrl+A.
  2. Remove hidden accidents.Merge unintended doubles, recalculate normals, and delete interior faces that serve no purpose.
  3. Create simple collision in Godot.Prefer one or a few boxes for furniture; collision does not need every bevel.
  4. Walk around it in the game.Check scale, shading, floor contact, collision, and readability under engine lighting.

The quickest entry for low-poly, voxel-like, or stylized furniture. Cuboid modeling, automatic UV templates, texture painting, and browser access keep the first prop small and finishable.
