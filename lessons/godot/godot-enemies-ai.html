    01 / MODEL

    Finite state machine

    One enum prevents impossible behavior.

    Beginners often write enemy AI with separate booleans: is_patrolling, is_chasing, and is_returning. When two booleans accidentally stay true at the same time, the enemy twitches between goals. A Godot enum State guarantees the guard is in exactly one mode per physics frame.

    STATE 1

    PATROL

    Walks between assigned Marker3D waypoints at calm speed while watching for Player.

    STATE 2

    CHASE

    Continuously updates agent.target_position to Player and pursues at full speed.

    REMIX STATE

    INVESTIGATE

    Walks to last_known_pos and scans left/right before giving up the search.

    STATE 3

    RETURN

    Navigates back to the current patrol marker; switches back to PATROL on arrival.

    PATROL → CHASE: DetectionArea entered (+ LOS clear) CHASE → RETURN: Player exited / LOS blocked CHASE → INVESTIGATE → RETURN: Optional Remix RETURN → PATROL: agent.is_navigation_finished()
    Why use enum State instead of three separate booleans?

    Scene setup & NavMesh

    enemy.tscn Click a node
    Enemy · CharacterBody3D

    Root node moved by enemy.gd using velocity and move_and_slide(). Holds the state machine.

    Watch out: CharacterBody3D needs a physical CollisionShape3D child to collide with floors and walls.

    1. Add NavigationRegion3D to Main.Place your floor and wall meshes inside it as children, create a NavigationMesh resource, and press Bake NavMesh.
    2. Build the Enemy scene.Use CharacterBody3D as root with a mesh, physical collider, NavigationAgent3D, a wide DetectionArea, and a tight Hitbox.
    3. Add patrol Marker3D nodes.Drop 2–4 Marker3D points onto the teal baked floor in Main and assign them to the enemy’s exported patrol_points array.
    4. Isolate collision layers & masks.Put Player in group "player" (and Layer 2). Set DetectionArea’s mask to only detect Player so walls never trigger chase.
    5. Verify with Debug navigation.Enable Debug → Visible Navigation and watch the path bend around obstacles in real time.
    Layers vs. Masks: A body’s Layer says “what I am.” An Area3D or RayCast3D’s Mask says “what I scan for.” Setting DetectionArea to scan only the Player layer prevents walls, floors, and collectibles from firing false body_entered signals.

    03 / CODE

    Core Godot 4 script

    Ask NavigationAgent3D for the next safe step.

    This production-ready enemy.gd fixes the three most common student pitfalls: waiting one physics frame for NavMesh registration, keeping movement horizontal with gravity, and separating contact damage from detection range.

    enemy.gd · Godot 4 
    extends CharacterBody3D

enum State { PATROL, CHASE, RETURN }

@export var patrol_speed := 2.6
@export var chase_speed := 3.8
@export var patrol_points: Array[Marker3D]

@onready var agent: NavigationAgent3D = $NavigationAgent3D

var state := State.PATROL
var player: Node3D
var patrol_index := 0

func _ready() -> void:
    await get_tree().physics_frame
    if not patrol_points.is_empty():
        agent.target_position = patrol_points[0].global_position

func _physics_process(delta: float) -> void:
    match state:
        State.PATROL: patrol()
        State.CHASE: chase()
        State.RETURN: return_to_patrol()
    follow_path(delta)

func patrol() -> void:
    if agent.is_navigation_finished() and not patrol_points.is_empty():
        patrol_index = (patrol_index + 1) % patrol_points.size()
        agent.target_position = patrol_points[patrol_index].global_position

func chase() -> void:
    if is_instance_valid(player):
        agent.target_position = player.global_position

func return_to_patrol() -> void:
    if patrol_points.is_empty(): return
    if agent.is_navigation_finished():
        state = State.PATROL

func follow_path(delta: float) -> void:
    if not is_on_floor():
        velocity.y -= 9.8 * delta
    if agent.is_navigation_finished():
        velocity.x = 0.0
        velocity.z = 0.0
        move_and_slide()
        return
    var next := agent.get_next_path_position()
    var dir := global_position.direction_to(next)
    dir.y = 0.0
    dir = dir.normalized()
    var active_speed := chase_speed if state == State.CHASE else patrol_speed
    velocity.x = dir.x * active_speed
    velocity.z = dir.z * active_speed
    rotation.y = lerp_angle(rotation.y, atan2(-dir.x, -dir.z), 10.0 * delta)
    move_and_slide()

func _on_detection_area_body_entered(body: Node3D) -> void:
    if body.is_in_group("player"):
        player = body
        state = State.CHASE

func _on_detection_area_body_exited(body: Node3D) -> void:
    if body == player:
        player = null
        state = State.RETURN
        if not patrol_points.is_empty():
            agent.target_position = patrol_points[patrol_index].global_position

func _on_hitbox_body_entered(body: Node3D) -> void:
    if body.is_in_group("player") and body.has_method("take_damage"):
        body.take_damage(1)

    enum State: Replacing multiple booleans (is_chasing, is_returning) with one enum makes impossible overlapping states mathematically unreachable.

    Navigation is not collision. NavigationAgent3D only computes a path; CharacterBody3D + CollisionShape3D still handle physical walls, gravity, and slopes.

    04 / DAMAGE

    Fair challenge

    Telegraph danger, gate damage, and respawn cleanly.

    Try setting Damage cooldown to 0.0 s in the studio above and walk into the guard—without invulnerability frames (i-frames), 60 physics ticks per second drain all 3 HP almost instantly. Fair enemies follow three rules:

    1. Telegraph first

    Flash an amber light or play a chirp for ~0.35s before starting CHASE so surprise hits feel fair.

    2. Cooldown i-frames

    Lock can_take_damage for 1.0s after each hit and blink the player mesh to communicate safety.

    3. Clean respawn

    Emit health_changed to the HUD, move Player back to SpawnPad, and restore full health.

    player.gd · health, cooldown & respawn 
    signal health_changed(current: int, max_hp: int)

@export var max_health := 3
@export var spawn_point: Marker3D

var health := max_health
var can_take_damage := true

func take_damage(amount: int) -> void:
    if not can_take_damage: return
    can_take_damage = false
    health = max(0, health - amount)
    health_changed.emit(health, max_health)
    if health <= 0:
        respawn()
    await get_tree().create_timer(1.0).timeout
    can_take_damage = true

func respawn() -> void:
    health = max_health
    health_changed.emit(health, max_health)
    if spawn_point:
        global_position = spawn_point.global_position
    velocity = Vector3.ZERO
    Optional Upgrade: Add RayCast3D Line of Sight + INVESTIGATE state in Godot 4

    Ready to implement what you tested with the RayCast3D and INVESTIGATE switches in the studio? Add a RayCast3D child named LineOfSight to Enemy and upgrade your state enum:

    enemy_investigate.gd · Line of sight + search 
    enum State { PATROL, CHASE, INVESTIGATE, RETURN }

@onready var los: RayCast3D = $LineOfSight
var last_known_pos := Vector3.ZERO
var scan_timer := 0.0

func can_see_player() -> bool:
    if not is_instance_valid(player): return false
    los.target_position = los.to_local(player.global_position + Vector3.UP)
    los.force_raycast_update()
    return not los.is_colliding() or los.get_collider() == player

func investigate(delta: float) -> void:
    if can_see_player():
        state = State.CHASE
        return
    if agent.is_navigation_finished():
        scan_timer -= delta
        rotate_y(2.2 * delta)
        if scan_timer <= 0.0:
            state = State.RETURN
            agent.target_position = patrol_points[patrol_index].global_position
    05 / DEBUG

    Enemy AI Debug Clinic

    Six classic Godot AI bugs—and how to spot each one.

    1. Guard stands completely still

    Cause: NavMesh was never baked, or patrol_points is empty / placed off the teal mesh.

    Fix: Select NavigationRegion3D, click Bake NavMesh, and verify await get_tree().physics_frame in _ready().

    2. Guard jitters or spins at Marker3D

    Cause: Target distance threshold is too small, or Marker3D floats slightly above the floor.

    Fix: Snap patrol markers to floor level and keep agent.target_desired_distance around 0.5 m.

    3. Guard sees through solid walls

    Cause: DetectionArea is a pure sphere trigger—it ignores walls unless paired with a raycast.

    Fix: Add a RayCast3D aimed at the player and require can_see_player() before entering CHASE.

    4. Guard never detects Player

    Cause: Player is not in the "player" group, or DetectionArea’s collision mask skips Player’s layer.

    Fix: Check Node → Groups on Player and confirm DetectionArea.monitoring and masks match.

    5. Guard gets snagged on doorway corners

    Cause: NavMesh agent_radius is smaller than the enemy’s physical BodyCollision radius.

    Fix: Set NavigationMesh.agent_radius slightly larger than the enemy capsule and rebake.

    6. Player loses all HP in one touch

    Cause: Contact check runs every physics frame with no invulnerability cooldown.

    Fix: Gate take_damage() behind can_take_damage and a 1.0 s timer.
