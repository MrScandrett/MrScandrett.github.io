Your Assignment

Find, create, or 3D-print an artifact, landmark, or animal that interests you. Convert it to a GLB file using tools like Blender or specialized scanning software. Upload it here with a title, description, and artifact type. Your model will be added to the shared Virtual Reality Museum for all students to explore.

Artifact Ideas

  • Historical Artifacts: Ancient pottery, coins, tools, sculptures from museums
  • Landmarks: Famous buildings, monuments, natural formations
  • Living Things: Insects, dinosaurs, organisms scanned or photographed
  • Cultural Objects: Masks, ceremonial items, musical instruments
  • Archaeological Finds: Fossils, archaeological dig finds, reconstructed objects

How to Create a GLB File

Using Blender (Free & Recommended)

  1. Open or import your 3D model in Blender
  2. Select the model in the outliner
  3. Go to File → Export As → glTF Binary (.glb)
  4. Choose a filename (e.g., "greek-amphora.glb")
  5. Click "Export glTF Binary"

Using Photogrammetry Apps

  • Meshroom (Free): Create 3D models from photos
  • Polycam: Mobile app for 3D scanning via phone
  • Capture One: Professional 3D reconstruction

File Requirements

  • Format: GLB (glTF Binary)
  • Maximum size: 50 MB
  • Recommended polygon count: under 500k triangles for smooth VR performance
  • All textures and materials must be embedded in the GLB file
