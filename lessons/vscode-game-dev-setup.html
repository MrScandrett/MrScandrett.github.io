Mission 2 · Build the base

✅ Seven Quick Checkpoints

Click a checkpoint when it works. Your progress is saved on this device: 0 / 7.

Let's get started!

  • ✓
    1. Get VS Code. Visit code.visualstudio.com, choose your computer type, and run the installer. School device blocked? Ask your teacher.
  • ✓
    2. Make your game folder. Create a folder named my-game. In VS Code choose File → Open Folder, then select it.
  • ✓
    3. Add Live Server. Click the Extensions icon (four squares), search Live Server by Ritwick Dey, and choose Install.
  • ✓
    4. Add Prettier. Search for Prettier - Code formatter and install it. Prettier keeps your code tidy.
  • ✓
    5. Create the launch file. In the Explorer panel, choose New File and name it exactly index.html.
  • ✓
    6. Launch Live Server. Right-click index.html → Open with Live Server. A browser tab should open. A blank page is a win—we haven’t added the game yet!
  • ✓
    7. Find the terminal. Choose Terminal → New Terminal. You don’t need to type anything; just find it, then close it with the trash-can icon.

Tip: You can click a completed checkpoint again to undo it.

Mission 3 · Launch a game

🚀 Make Something Move

Replace everything inside index.html with the code below. Save it, click the game, then use the arrow keys. You just built a one-file game!

Paste into index.html
<!doctype html>
<title>My Tiny Game</title>
<style>
  body { margin: 0; background: #101827; overflow: hidden; }
  #hero { position: absolute; font-size: 48px; left: 40px; top: 80px; }
  p { color: white; font: 20px sans-serif; text-align: center; }
</style>
<p>Click here, then use ← and →</p>
<div id="hero">🛸</div>
<script>
  let x = 40;
  const hero = document.querySelector("#hero");
  addEventListener("keydown", event => {
    if (event.key === "ArrowRight") x += 20;
    if (event.key === "ArrowLeft") x -= 20;
    hero.style.left = x + "px";
  });
</script>
Remix challenge: Swap 🛸 for 🐸, 🐉, 🏎️, or your favorite emoji. Change 20 to 50. What happens?

Quest Complete: Game-Dev Ready

You can open a project, edit a file, launch Live Server, test a game, and find bug clues. That is a real development workflow.

Exit ticket: Show a classmate your moving emoji and tell them where you would look for a red error.

Win Conditions

  • Install VS Code and Live Server
  • Open a project folder
  • Launch and remix a tiny browser game
  • Use the change-save-test-notice loop
  • Find bug clues in the Console

Mystery Word: localhost

localhost means “this computer.” Live Server lets your own computer temporarily serve the game to your browser. It is not publishing the game to the internet.

Stuck?

Check spelling and file names first. Then read the first red Console message. Still stuck? Show a partner what you expected and what actually happened.

Optional Power-Ups

  • Auto-save: Enable File → Auto Save so you never forget to save before checking the browser.
  • Split editor: Right-click a tab → "Split Right" to see your HTML and JS side-by-side.
  • Bigger text: Press Ctrl/⌘ + + to zoom in if code is hard to read.
  • Format code: Right-click in your file → "Format Document" after installing Prettier.
  • Don’t extension-shop: Live Server and Prettier are enough for today. Build first; add tools when you need them.
