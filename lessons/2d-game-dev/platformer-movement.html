01 / WHY

Where this comes from

Good controls quietly forgive the player.

2018

Modern pixel-art platformers such as Celeste are known for being precise yet forgiving: you can still jump a few frames after running off a ledge, and a jump pressed just before landing still counts. Players rarely notice these helpers — they just feel that the game is fair.

The Flappy tutorial uses the simplest version of this physics: one impulse up, constant gravity down. Here you add running and the forgiveness tricks.

03 / THEORY

Theory: velocity, acceleration, arcs

Move toward a target speed; let gravity bend the path.

player.update(dt) · JavaScript
const dir = (keys.right ? 1 : 0) - (keys.left ? 1 : 0);
const rate = dir ? accel : decel;                 // speed up vs brake
vx = approach(vx, dir * maxRun, rate * dt);       // never snaps — it ramps

coyote = onFloor ? COYOTE : coyote - dt;          // grace after leaving a ledge
buffer = jumpPressed ? BUFFER : buffer - dt;      // grace before landing
if (buffer > 0 && coyote > 0) { vy = -jumpVel; buffer = coyote = 0; }

if (!jumpHeld && vy < 0) vy *= jumpCut;           // let go early → shorter hop
vy += gravity * (vy > 0 ? fallMul : 1) * dt;      // fall faster than you rise

A jump is a parabola. Its height depends on the launch speed and gravity: height = v² ÷ 2g. With v = 280 px/s and g = 900 px/s² that is about 44 px — just under three tiles. Level design (lesson 09) depends on this number, so measure it before you build platforms.
