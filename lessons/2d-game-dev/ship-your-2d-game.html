01 / WHY

Where this comes from

Publishing used to need a factory.

2000s

Shipping a game once meant manufacturing cartridges or discs. In the 2000s, browser-game portals let anyone publish a game that ran from a link. Today a folder with index.html is a complete game — the same way this pathway’s starter pack works.

02 / STATES

Game states

Title → play ⇄ pause → win.

Lesson 08’s state machine works for whole screens too. The game only updates physics in play; every other state waits for a key.

game states · JavaScript
let mode = "title";
function update(dt) {
  if (mode !== "play") { if (pressed.start) mode = "play"; return; }
  if (pressed.pause) { mode = "paused"; return; }
  stepPhysics(dt);
  if (allParcelsDelivered()) { mode = "win"; saveBest(time); }
}
function saveBest(t) {
  const best = Number(localStorage.getItem("best")) || Infinity;
  if (t < best) localStorage.setItem("best", String(t));  // durable fact, not live state
}

03 / PACK

Package it

Take your art with you.

  1. Download your art.js using the button above. It holds your palette, every frame, your tiles and your level.
  2. Download the starter pack and unzip it. Replace its art.js with yours.
  3. Open index.html in a browser. Your courier, tiles and level run with no server and no install.
  4. Read game.js. It is the same engine in about 300 commented lines, ready for new enemies, levels and rules.

Controls on screen

Show arrows/WASD, Space and P before play. Don’t make players guess.

Credits

List every sound, font or image you didn’t make, with its creator and licence.

One-sentence goal

“Collect every parcel, then reach the mailbox.” If you can’t say it in one sentence, simplify.

Fresh-computer test

Open the zip on another device. Missing files only show up away from your own machine.
