01 / WHY

Where this comes from

Tiles let a tiny memory hold a huge world.

1980

Pac-Man’s maze is built on a grid of tiles, and console games of the 1980s stored levels as lists of tile numbers instead of full pictures. A screen of 8 × 8 tiles needs one byte per tile — far less than one byte per pixel.

The Maze tutorial already uses this idea: its walls are a grid. Here you draw the tiles yourself and see the grid as text.

04 / AUTOTILE

Theory: autotiling

Let neighbours choose the edge.

Hand-placing “top-left corner”, “top edge”, “right wall”… is slow. Autotiling looks at the four neighbours and adds up a bitmask: up = 1, right = 2, down = 4, left = 8. The total (0–15) picks one of 16 tile variants. Click cells below.

4-bit autotileClick to add or remove ground

bitmask · JavaScript
function mask(x, y) {
  return (filled(x, y - 1) ? 1 : 0)  // up
       + (filled(x + 1, y) ? 2 : 0)  // right
       + (filled(x, y + 1) ? 4 : 0)  // down
       + (filled(x - 1, y) ? 8 : 0); // left
}
const variant = groundTiles[mask(x, y)]; // 16 hand-drawn variants
