01 / WHY

Where this comes from

Rectangles have powered collisions since Pong.

1972–1978

Pong’s ball bounced when its rectangle overlapped a paddle’s rectangle; Space Invaders checked whether a shot’s rectangle touched an invader. Axis-aligned rectangles are still the first tool every 2D engine reaches for, because the overlap test is four comparisons.

AABB overlap · JavaScript
function overlaps(a, b) {
  return a.x < b.x + b.w && a.x + a.w > b.x &&
         a.y < b.y + b.h && a.y + a.h > b.y;
}

The courier’s hitbox is 10 × 14 inside a 16 × 16 drawing. Spikes use an even smaller box. Hitboxes slightly smaller than the art make near-misses feel fair — the Shooter tutorial does the same with bullets.

02 / STEP

Collision stepper

Watch one frame in slow motion.

Each frame has two halves. Move: put the box where its velocity says (red dashed outline). Resolve: if it is inside a solid tile, push it out and zero the velocity on that axis.

Step through collisionsTry every scenario with both methods

  • Sliding over tile seams with “both at once”: the box overlaps the next floor tile by a sliver horizontally and vertically, the smaller push is sideways, and the courier snags on a flat floor.
  • Very fast fall with no sub-steps: the box moves 26 px in one step and lands entirely below a 16 px floor — it never overlapped, so nothing stopped it. That is tunnelling.
03 / THEORY

The fix

Move one axis at a time, in small steps.

moveX then moveY · JavaScript
function moveX(dx) {
  p.x += dx;
  for (const t of solidTilesTouching(p)) {
    p.x = dx > 0 ? t.left - p.w : t.right;   // push back out the way we came
    p.vx = 0;
  }
}
function moveY(dy) {
  p.y += dy; p.onFloor = false;
  for (const t of solidTilesTouching(p)) {
    if (dy > 0) { p.y = t.top - p.h; p.onFloor = true; } else p.y = t.bottom;
    p.vy = 0;
  }
}
const steps = Math.ceil(Math.max(Math.abs(dx), Math.abs(dy)) / 4); // ≤ 4 px each
for (let i = 0; i < steps; i++) { moveX(dx / steps); moveY(dy / steps); }
One-way platformOnly collide when falling (dy > 0) and the feet were above the plank’s top last step. Rising through it, or dropping with ↓ + jump, passes straight through.
