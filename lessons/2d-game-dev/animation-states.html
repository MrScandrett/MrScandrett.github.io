03 / THEORY

Theory: rules in priority order

Check the most important condition first.

pick a state every physics step · JavaScript
function chooseState() {
  if (!p.onFloor) return p.vy < 0 ? "jump" : "fall";  // air beats everything
  if (p.landTimer > 0) return "land";                  // short recovery pose
  if (Math.abs(p.vx) > 8) return "run";
  return "idle";
}
const next = chooseState();
if (next !== p.state) { p.state = next; p.animTime = 0; } // restart only on change
sprite.flipX = p.facing < 0;                               // one sheet, both directions
Why physics, not keysHolding → against a wall means “run” to the keyboard but the body isn’t moving. Holding jump in the air means “jump” to the keyboard but the body is falling. Read velocity and floor contact instead.
