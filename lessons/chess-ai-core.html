    Board Eval Balanced
    How This Version Works Standard 8×8 setup. Win by checkmate (or draw by stalemate). Each model era changes search depth, style, and consistency. No castling or en passant in this classroom build.
    Turochamp (1951) Alan Turing's hand-simulated chess program. Used simple material and mobility heuristics — played one move per hour by hand calculation.
    Mac Hack VI (1967) First chess program to compete in a human tournament. Introduced better evaluation functions and iterative deepening search.
    Deep Blue Style (1997) IBM's landmark system that defeated Kasparov. Evaluated ~200 million positions per second using custom hardware and alpha-beta pruning.
    Modern Engine Style (2020s) Neural-network evaluation combined with MCTS or alpha-beta. Engines like Stockfish NNUE use learned position weights alongside classical search.
    What to Watch For Switch eras mid-session and compare how quickly the AI develops pieces, how aggressively it attacks, and how often it misses tactics at depth 1 vs depth 3.
