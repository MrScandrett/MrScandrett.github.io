02 / GLOBAL

Autoload

Keep cross-scene data in one small manager.

Create game_state.gd, then add it through Project Settings → Globals → Autoload as GameState.

game_state.gd
extends Node
var current_level := 1
var best_time := 999.0
var checkpoint := Vector3.ZERO

func start_game() -> void:
    current_level = 1
    get_tree().change_scene_to_file("res://levels/level_1.tscn")

func retry_level() -> void:
    get_tree().reload_current_scene()
Keep it small: Autoloads are useful for data that truly must survive scene changes. Do not turn GameState into a home for every unrelated script.
03 / PAUSE

Control time

Pause gameplay, not the menu.

pause_menu.gd
extends Control

func _unhandled_input(event: InputEvent) -> void:
    if event.is_action_pressed("pause"):
        var paused := not get_tree().paused
        get_tree().paused = paused
        visible = paused
        Input.mouse_mode = Input.MOUSE_MODE_VISIBLE if paused else Input.MOUSE_MODE_CAPTURED

Set the pause menu’s Process Mode to Always. It must receive the pause action both before the game pauses and while it is paused so the same key can resume.

04 / SAVE

Persistence

Save only the facts you need later.

JSON save data
const SAVE_PATH := "user://save.json"

func save_progress() -> void:
    var data = {"level": current_level, "best_time": best_time}
    var file := FileAccess.open(SAVE_PATH, FileAccess.WRITE)
    file.store_string(JSON.stringify(data))

func load_progress() -> void:
    if not FileAccess.file_exists(SAVE_PATH): return
    var file := FileAccess.open(SAVE_PATH, FileAccess.READ)
    var data = JSON.parse_string(file.get_as_text())
    if typeof(data) != TYPE_DICTIONARY: return
    current_level = int(data.get("level", 1))
    best_time = float(data.get("best_time", 999.0))

Remix challenge

Add a reset-save button with a confirmation step. Test the experience as if a player clicks it accidentally.

05 / CHECKPOINT

Recovery

Respawn at the last activated checkpoint.

Create a Checkpoint scene with an Area3D, collision shape, visible marker, and SpawnPoint child. Connect body_entered.

checkpoint.gd
extends Area3D
var activated := false

func _on_body_entered(body: Node3D) -> void:
    if activated or not body.is_in_group("player"): return
    activated = true
    GameState.checkpoint = $SpawnPoint.global_position
    $AnimationPlayer.play("activate")

# In player.gd
func respawn() -> void:
    health = max_health
    global_position = GameState.checkpoint
    velocity = Vector3.ZERO
