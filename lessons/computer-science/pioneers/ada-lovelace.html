Who Was Ada Lovelace?

Augusta Ada King, Countess of Lovelace (December 10, 1815 – November 27, 1852) was a British mathematician and writer celebrated as the world’s first computer programmer. Her father was the famous Romantic poet Lord Byron, who left England when Ada was one month old. Hoping to steer Ada away from her father’s volatility, her mother — Anne Isabella Milbanke, herself mathematically gifted — arranged rigorous tutoring in mathematics, logic, and astronomy.

At seventeen, mentored by scientist Mary Somerville, Ada attended a London salon hosted by inventor Charles Babbage and saw a working section of his Difference Engine. While visitors admired its brass wheels, Ada asked how the machine worked and soon began studying Babbage’s far more ambitious design: the Analytical Engine, a steam-driven, programmable mechanical computer.

In 1842, Italian mathematician Luigi Menabrea published a French summary of Babbage’s 1840 Turin lectures. Babbage invited Ada to translate it for Taylor’s Scientific Memoirs. She translated the paper and appended seven essays — Notes A through G — nearly three times as long as Menabrea’s original text. Published in 1843, Note G laid out a 25-operation algorithm to compute Bernoulli numbers, while Note A articulated why a programmable machine could manipulate music, language, and symbols beyond pure arithmetic.

“The Analytical Engine weaves algebraical patterns just as the Jacquard-loom weaves flowers and leaves.” — Ada Lovelace, Note A (1843)

How does Ada connect to Alan Turing’s 1950 paper?
In Note G, Ada cautioned that the Engine “has no pretensions whatever to originate anything. It can do whatever we know how to order it to perform.” In 1950, Alan Turing quoted this as “Lady Lovelace’s Objection” when debating whether machines could learn and surprise their programmers.
Was the Analytical Engine ever built?
No complete Analytical Engine was built in Babbage’s lifetime. His son Henry Babbage assembled a small trial Mill and printing mechanism between 1888 and 1910 (now at the Science Museum in London). Separately, the Science Museum built a working replica of the simpler Difference Engine No. 2 in 1991 (adding its printer in 2002). Today, the Plan 28 project aims to construct a full Analytical Engine from Babbage’s surviving drawings.
Why does Babbage’s decimal card differ from a modern binary card?
Modern electronics naturally represent two states — voltage OFF (0) or ON (1) — so a punched card in the 1960s encoded bits in base 2. Babbage’s mechanical wheels each had 10 teeth (digits 0 through 9), so his Number Cards encoded base-10 decimal digits directly. You can compare both card styles in Tab 2 of the studio above!

Decoding Note G & History’s First Printed Bug

Bernoulli numbers appear in sums of powers (like 1² + 2² + … + k²) and series expansions across calculus. Because each new Bernoulli number depends on every previous one, computing them by hand is tedious — making it a tough stress test for a programmable machine.

Catching the 1843 Operation 4 Bug: In the original printed table of Note G, Operation 4 reads V5 / V4 instead of V4 / V5. Because V4 = 2n − 1 and V5 = 2n + 1, swapping those two registers flips the fraction upside down (for n = 1, producing 3/2 instead of 1/6!). Toggle 1843 Op 4 Bug: On in Tab 1 to watch this 183-year-old bug propagate live across the Store.

Indexing difference & sign note: Ada numbered the nonzero terms B₁, B₃, B₅, B₇ (1/6, −1/30, 1/42, −1/30). Modern textbooks index those same even terms as B₂, B₄, B₆, B₈ (starting with B₀ = 1 and B₁ = −1/2). Also notice Operation 24: the 1843 print listed + on transfer to V24, expecting the Result column to invert the negative accumulator V13 so B₇ = −1/30.

Solving for B₂ (Ada’s B₁) Step by Step

  1. B₀ + 3 × B₁ + 3 × B₂ = 0Modern recurrence equation where B₀ = 1 and B₁ = −1/2 are already known.
  2. 1 + 3 × (−1/2) + 3 × B₂ = 0Substitute the known starting fractions.
  3. −1/2 + 3 × B₂ = 0Combine 1 − 3/2 = −1/2.
  4. B₂ = (1/2) ÷ 3 = 1/6Solve for the unknown term — matching Ada’s V21 = 1/6!

Key Contributions, Vocabulary & Legacy

1. First Published Machine Algorithm (1843)

Note G laid out exact Store columns, operation sequence, and control flow for an unbuilt general-purpose machine.

2. Loops & Nested Iteration

Operations 13–23 repeat an inner summation block while Operation 25 wraps an outer loop across n = 1, 2, 3, 4.

3. Conditional Branching

Operations 7 and 12 inspect whether V10 reaches zero to skip unnecessary inner passes — early if / else control flow.

4. Symbolic Computing (“Poetical Science”)

Note A foresaw that machines manipulating numbers could represent music, words, or weaving patterns if properly encoded.

5. Hardware vs. Software Separation

Swapping card decks transforms what the same brass mechanism computes — the core idea of programmable software.

6. The “Ada” Programming Language (1980)

Standardized as MIL-STD-1815 in her honor and still used in aviation, rail signaling, satellites, and safety-critical systems.

Vocabulary Reference

Algorithm
A finite, ordered sequence of unambiguous instructions that solves a problem or performs a computation.
The Mill & The Store
Babbage’s arithmetic unit (ancestor of the CPU) and column gear memory (ancestor of RAM and registers).
Register Overwrite
Writing a new value into a register replaces whatever value sat there previously; old results must be saved elsewhere first.
Conditional Branch
Testing a condition (such as V10 = 0) to decide which card operation executes next.
Loop (Inner & Outer)
Rewinding cards to repeat instructions: Note G nests an inner summation loop (Ops 13–23) inside an outer term loop (Op 25).
Trace Table
Tracking each register’s contents by hand step by step to verify logic and catch bugs before running code.
Symbolic Representation
Encoding non-numeric ideas — musical pitches, letters, loom threads — as numbers a machine can process.
Decimal vs. Binary Cards
Babbage’s Engine used base-10 (0–9) decimal wheels, whereas 20th-century electronic computers used base-2 (0/1) binary.

Easy2. Which part of the Analytical Engine stored up to 1,000 numbers in columns of gears, acting as the ancestor of modern RAM?

Hint: The Mill performed arithmetic (like a CPU); the memory columns where numbers sat were called The Store.

Easy3. What mathematical sequence did Note G’s 25-operation algorithm compute?

Hint: Check the title of Note G’s diagram — it computed Bernoulli numbers (1/6, −1/30, 1/42, −1/30).

Medium4. In Babbage’s hardware, what number base did the Store gear wheels actually use (unlike modern binary electronic computers)?

Hint: Each gear wheel had ten teeth numbered 0 through 9 — base 10 (decimal).

Medium5. On an 8-bit modern binary punch card (hole weights 128, 64, 32, 16, 8, 4, 2, 1), holes 1, 3, and 8 are punched. What decimal number does this encode?

Hint: Add the punched bit weights: 128 (hole 1) + 32 (hole 3) + 1 (hole 8) = 161.

Medium6. In Note G, Operation 7 computes V10 ← V3 − V1. When n = 4, how many times does the inner loop (Operations 13–23) execute before exiting?

Hint: Op 7 sets V10 = 3, Op 12 sets V10 = 2, and Ops 13–23 decrement V10 by 1 each pass until it hits 0 (try running n = 4 in Tab 1!).
