Controls

Build: tap a part, tap the table, drag to size it. Drag handles to reshape. Arrow keys move the selected part (Shift moves farther). Ctrl/Cmd+D duplicates, Delete removes, Ctrl/Cmd+Z undoes.

Play: Touch: hold the Left and Right buttons to flip; hold Launch and release to shoot. Keyboard: Z / ← left flipper · / or → right flipper · hold Space to pull the plunger, release to launch · P pauses · Esc goes back to Build. Your design saves automatically in this browser. Use Settings to change the table’s theme, skin, and background.

Game Design & Development · Build it, then play it

Pinball Construction Set

In 1983 Bill Budge shipped a game where the main event was the building: pick parts from a bin, drop them on a blank table, press play, and your design is a real machine. This is the same idea rebuilt for the browser, with a physics engine small enough to read in one sitting.

How the machine works

A table is just data

Every part is a few numbers: where it sits, how big it is. Press Save file and you get a small JSON file you can read, edit and hand to a friend. The editor and the game never share anything else.

Physics in small steps

The ball moves 480 tiny steps per second. At 2,000 pixels per second it still travels less than half its own width per step, so it can never skip through a wall. That trick is called substepping.

Flippers are moving walls

A flipper is a tapered rod that swings. When the ball touches it, the game measures how fast that exact spot is moving and adds it to the bounce. Hit near the tip and the ball flies.

Bumpers cheat on purpose

A real bumper has a solenoid that punches the ball. Here a bumper guarantees a minimum outgoing speed. Real rules, plus a little arcade lie.

Design challenges

  1. Make it winnable. Add a wall that guides the ball toward the targets. Can a new player light all three?
  2. Make it fair. Get the ball to drain on purpose only when the player misses. No dead zones where it sits still.
  3. Make it yours. Rename the table, build a theme (space, jungle, a school day), and swap tables with a classmate.
  4. Break it. Stack bumpers touching each other. What does the ball do? Why does the physics need a speed limit?

History

Bill Budge, who wrote Raster Blaster for the Apple II, started Pinball Construction Set in 1982 and Electronic Arts published it in 1983. Instead of writing one more pinball game, he wrote a toolkit for building them, and the idea of "play it, then change it" shaped a generation of level editors. This rebuild is original code and art; it borrows the idea, not the pixels.
