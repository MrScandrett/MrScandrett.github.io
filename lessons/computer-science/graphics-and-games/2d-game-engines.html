0The quick answer

For a first JavaScript prototype, Kaplay is a useful starting point. For a project built around tilemaps and scene organization, explore Phaser 3. Both can build substantial games; choose based on the features, examples, and code you understand.

🌱Kaplay = easier startShorter code and quick prototypes
🧰Phaser = more toolsMore setup, but room to build bigger

1What does a game engine do?

Think of a game engine as a toolbox for making games. It gives you ready-made code for jobs that almost every game needs.

  • Scenes — switch between a menu, a level, and a game-over screen
  • Sprites — show and animate characters, enemies, and items
  • Physics — add gravity, speed, bouncing, and collisions
  • Controls — read the keyboard, mouse, touchscreen, or gamepad
  • Sound — play music and sound effects
  • Loading — prepare images and sounds before the game begins
  • Camera — follow the player, zoom, or shake after a big hit
Remember: Coding from scratch helps you learn how games work. An engine helps you make a bigger game faster. Both are useful skills.

2Meet Kaplay and Phaser

Both engines are free and work in a web browser. They can make the same kinds of 2D games, but they feel different to use.

Kaplay Beginner Friendly

  • Short, readable code
  • Add abilities like gravity as building blocks
  • Great for platformers and small arcade games
  • Fast setup for class projects and game jams

Phaser 3 Scene & Map Tools

  • Uses an organized scene system
  • Includes several physics choices
  • Strong tools for maps, effects, and cameras
  • Better for larger, more detailed games

3How a scene starts and runs

A scene is one part of a game, such as the menu, a level, or the game-over screen. A common Phaser 3 scene uses these lifecycle methods (an optional init() can come first). Loading and setup happen when the scene starts; update repeats while it runs:

preload() Get images and
sounds ready
→
create() Build the level
and add the player
→
update() Repeat: move and
check collisions

Kaplay does these jobs too, but hides more of the setup. You create a scene, use add() to place objects, and Kaplay keeps the game running.

💭Quick checkWhich step repeats many times each second? Answer: update().

4Compare the code

These are partial API sketches, not complete playable games: the floor and collision setup are omitted. Switch tabs and match each instruction to the frame lab. Kaplay also needs setGravity() for falling; Phaser needs a floor collider or world bounds for blocked.down to become true.

// Kaplay — minimal setup, very readable
kaplay();

scene("game", () => {
  // create a player with components
  const player = add([
    rect(32, 32),           // draw a 32×32 rectangle
    pos(200, 200),          // starting position
    color(BLUE),             // color it blue
    area(),                  // enable collision detection
    body(),                  // enable gravity/physics
    "player",               // tag for collision queries
  ]);

  // movement — checked every frame automatically
  onKeyDown("left",  () => player.move(-200, 0));
  onKeyDown("right", () => player.move( 200, 0));
  onKeyPress("up",    () => player.jump());
});

go("game");
// Phaser 3 — explicit scene class, more structured
class GameScene extends Phaser.Scene {
  preload() {
    // load assets here — images, tilemaps, audio
  }

  create() {
    // create player as a rectangle physics body
    this.player = this.add.rectangle(200, 200, 32, 32, 0x3b82f6);
    this.physics.add.existing(this.player);
    this.player.body.setGravityY(400);

    // set up cursor keys
    this.cursors = this.input.keyboard.createCursorKeys();
  }

  update() {
    const body = this.player.body;
    body.setVelocityX(0);

    if (this.cursors.left.isDown)  body.setVelocityX(-200);
    if (this.cursors.right.isDown) body.setVelocityX( 200);
    if (this.cursors.up.isDown && body.blocked.down)
      body.setVelocityY(-500);
  }
}

new Phaser.Game({ scene: GameScene, physics: { default: 'arcade' } });

5Four key words

🧍 SpriteA 2D picture used for a player, enemy, coin, or other game object.
🎞️ Sprite sheetMany animation pictures packed into one image, like frames in a flipbook.

Key Vocabulary

Game Engine
A library or tool that provides reusable systems (rendering, physics, audio, input) so you don't build them from scratch.
Scene
A self-contained state of the game — main menu, level 1, boss fight, game over screen.
Sprite
A 2D image (PNG) used to visually represent a game object — player, enemy, coin, tile.
Sprite Sheet
A single image file containing many animation frames packed together in a grid.
Tilemap
A grid of small tile images used to efficiently build and render game levels.
Tween
An animation of a numeric value over time (position, opacity, scale), typically with an easing function for smooth feel.
Component
In Kaplay, a behavior added to a game object — body(), area(), sprite(). Objects are built by composing components.
