How does move A onto B become an instruction? Take a sentence apart, match a rule, then test it with four blocks.

1 Split into words → 2 Match a rule → 3 Check and act

Words have jobs. Order gives them structure.

Tokenizing splits text into pieces called tokens. In this lab, each word is a token. Parsing checks their order against a grammar and builds a structured instruction. Understanding that structure does not mean the move is possible.

      Three experiments: where does it fail?
      
            
      
              
      Structure
      Try move onto A B. All the words look familiar, but their order does not match a rule. Repair the sentence. This is a syntax error.
      
              
      Reference
      Try move Z to table. The sentence matches the grammar, but there is no block Z. Parsing succeeded; checking the referenced object failed.
      
              
      World rules
      Reset, then run move B to table. It parses and B exists, but A is on top. Move A first and try again. The same sentence can have a different result in a different state.
      
            
      
            
      Try it with real objects
      Label four classroom objects A–D. Write “move”, “A”, “onto”, and “B” on four slips. One partner arranges the slips; another labels the action, source, relation, and destination, then checks whether the move is possible. Swap A and B. Explain what changed before touching the objects.
      
            
      This lab uses a small, fixed grammar. Parsers also give structure to code, calculator expressions, and data files. A general language system needs much more than these command patterns.
