Caesar has very few keys to try. Enigma hides repeated-letter patterns, but settings and procedures matter. RSA allows a public encryption key, yet only large, correctly used keys offer practical protection.

Caesar’s shift cipher

A fixed shift replaces each letter with another. With only 25 nonzero shifts, an interceptor can try every key; repeated letters also preserve patterns.

The Enigma Machine (1930s)

Rotating wheels changed the substitution with each keypress. Rotor order, starting positions, ring settings, and plugboard connections were parts of the key.

Bletchley Park (1939–45)

Polish mathematicians first broke military Enigma. Building on their work, Allied teams used likely plaintext, operating mistakes, and machines such as the British Bombe to test possible settings.

RSA (1977)

Rivest, Shamir, and Adleman introduced RSA, a public-key cryptosystem. Its security depends on large keys and careful protocols. This tiny, unpadded classroom model is not secure encryption.

AI Codebreaking (2026)

In September 2026, developer Carter Leffen set OpenAI's GPT-6 Astra loose on MVUEH, an 82-character German Army Enigma message from July 10, 1941, that had sat unbroken in public archives since 2005. Over roughly 10 hours, the AI searched archival scans, wrote its own Enigma simulator, and tested millions of settings. The break came from a crib: "Rosenow," a place name repeated in a related message solved the same day. The recovered plaintext asks for a march route and reports the sender's position — "Bitte um Angabe des Marschweges. Befinde mich in Rosenow, Rosenow. Sofort Funkantwort." Veteran researcher Frode Weierud verified the solution and logged it on his CryptoCellar archive, calling it the first hard Enigma problem broken with AI. It's the same idea as the Bombe to its left — mechanically testing candidate settings against a guessed piece of plaintext — just running on a language model instead of rotating drums.

Shift Ciphers
Symmetric Key The Caesar cipher uses the exact same key (the shift number) to lock and unlock the message. If the enemy steals the key, the system fails.
The Enigma
Polyalphabetic Instead of shifting every letter by 3, Enigma shifts every letter by a different amount because the right rotor steps before each letter is encrypted; the other rotors advance at turnover points.
A useful constraint The reflector bounces the signal back through the rotors. At the same rotor positions, if A maps to G, G maps to A. No letter maps to itself. This helped codebreakers reject impossible guesses, but was not enough to break Enigma on its own.
Public Key (RSA)
Asymmetric Key RSA solves the key-sharing problem. You publish a "Public Key" that anyone can use to encrypt a message to you. But only your secret "Private Key" can decrypt it.
Prime Math Multiplying primes gives N = p × q. Recovering the factors can be difficult when carefully chosen primes are extremely large. The small numbers here are easy to factor.
