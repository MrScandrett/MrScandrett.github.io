Limit Notes

WHAT THIS IS

A perceptron is a small guess machine. It learns by moving one straight line.

WHAT IT CAN'T DO

XOR cannot be solved by one line in two dimensions. This is a structural limit, not just undertraining.

HOW TO USE IT LIKE IT'S 1958

  • Set channels to (1,0). Run.
  • Try 0.1 learning rate first. Watch what changes.
  • Adjust W1 upward until output flips.
  • Switch to XOR. Can you draw one line that separates all points? Try.

Accessibility
What is a Perceptron? A single-layer binary classifier. It learns by moving one straight decision boundary whenever it misclassifies a training example. Invented by Frank Rosenblatt in 1958.
The Learning Rule w = w + η × error × x
If a dot is on the wrong side, the line shifts toward it. Learning rate η controls how big each step is.
AND and OR (work) Both are linearly separable — one straight line can divide class 0 from class 1. The perceptron converges to 100% accuracy.
XOR (does not work) XOR is not linearly separable. No single straight line can separate all four points. This is a structural limit of one-layer networks — not an issue of training more.
What Learning Rate Does Low (0.05): slow, stable steps. High (1.0): fast but can overshoot and oscillate. Try both on AND and watch how the line moves.
Geometry View Dots are training examples. The line is the current decision boundary. Glowing rings mark misclassified points — the line moves toward those each training step.
