Station 1

Variables & print()

A variable is a labeled box that holds a value. = stores a value in the box; it does not mean "equals" the way it does in math. print() shows a value on the screen.

robot_name = "Byte"
battery = 87
print(robot_name, "is at", battery, "percent.")

What does this print?

Pick the line you think Python would print.

Now fix it the other way: what variable name is missing from the blank so this code prints Level 5?

____ = 5
print("Level", level)

Look at the second line to see what name is used there.

Station 2

Data Types

Every value in Python has a type. The four you'll use constantly: str (text, in quotes), int (whole numbers), float (decimal numbers), and bool (True or False). Tap the correct type for each value.

"level 5"
42
3.5
True
"42"
10 > 3

Notice that "42" is a string because of the quotes — Python treats it as text, not a number.

Station 3

Operators

Arithmetic operators do math: + - * / plus two Python specials — // (floor division, drops the remainder) and % (modulo, keeps only the remainder). Comparison operators (== != > < >= <=) ask a yes/no question and produce a bool.

What does print(17 // 5) output?

Floor division throws away the leftover and rounds down.

What does print(17 % 5) output?

17 divided by 5 is 3 remainder 2 — % gives you just the remainder.

What does print("3" + "4") output?

Both sides are strings, so + glues the text together instead of adding numbers.

Station 4

Conditionals: if / elif / else

A conditional lets a program make decisions. Python checks each condition in order and runs the first block that is True — then skips the rest.

score = 72
if score >= 90:
    print("A")
elif score >= 70:
    print("B")
else:
    print("Keep practicing")

What prints?

72 is not ≥ 90, but it is ≥ 70 — and Python stops at the first true branch.

Fill in the comparison so the code below prints Access granted when pin is exactly 1234:

pin = 1234
if pin ____ 1234:
    print("Access granted")

Remember: a single = stores a value; this needs the "is equal to" operator.

Station 5

Loops: for & while

A for loop repeats once per item in a sequence — range(n) counts from 0 up to (but not including) n. A while loop repeats as long as a condition stays True.

for i in range(4):
    print(i)

What prints?

range(4) counts 0, 1, 2, 3 — four numbers, starting at zero.

Fill in the blank so this while loop prints 0 1 2 and then stops (it must not run forever):

count = 0
while count < 3:
    print(count)
    count = count + ____

Without changing count, the condition count < 3 would stay true forever — an infinite loop.

Station 6

Lists

A list holds many values in order, in square brackets. Items are numbered starting at 0. .append() adds an item to the end. len() counts how many items are in it.

pets = ["cat", "dog", "fish"]
pets.append("hamster")
print(pets[1])
print(len(pets))

What prints on the first line?

Counting starts at 0, so index 1 is the second item: "dog".

What prints on the second line — how many items are in pets after the .append()?

The list started with 3 items; .append("hamster") made it 4.

Station 7

Functions

A function is a reusable block of code. def defines it, the names inside the parentheses are parameters (placeholders), and return sends a value back out to whoever called it.

def double(x):
    return x * 2

print(double(5))
print(double(10))

What prints?

Each call passes a different x into the same function: 5×2=10, 10×2=20.

Complete the function so greet("Nova") returns "Hi, Nova!":

def greet(name):
    return ____

You can join strings with +, or use an f-string like f"Hi, {name}!".

Integration · Mini Challenge

Predict the Full Output

This program uses every rung of the ladder: a variable, a list, a loop, a conditional, and a function. Read it carefully, then type exactly what it prints — one line per print().

def status(hp):
    if hp > 0:
        return "alive"
    else:
        return "defeated"

team = [30, 0, 15]

for hp in team:
    print(hp, status(hp))

The loop runs once per number in team, calling status() fresh each time.

Lesson objective Students read and predict the output of real Python code covering variables, data types, operators, conditionals, loops, lists, and functions — then check their prediction instantly.
Why "predict the output," not a live interpreter? This lab intentionally skips running real Python in the browser. Predicting output first builds the mental model that makes an actual interpreter useful later — and it works on any device with zero setup.
Station 1–3 Read each code block aloud before choosing an answer. Naming the parts ("that's a variable, that's a string") builds vocabulary alongside syntax.
Station 4–5 For conditionals and loops, have students trace through the code by hand on paper first — write down each variable's value as it changes.
Station 6–7 Lists and functions are where most beginners stumble on off-by-one counting. Point out that indexing and range() both start at 0.
Mini Challenge This is the assessment moment: can a student trace a program that combines every rung of the ladder? Multiple correct output formats are accepted for near-misses in spacing.

Integer (int)A whole number, positive or negative, with no decimal point.
FloatA number with a decimal point, like 3.5.
Boolean (bool)Exactly one of two values: True or False.
