How Code Bridge works
  1. Prepare a request hereSelect files and describe one change. Copy the request into your teacher-approved AI chat.
  2. Bring the answer backPaste the AI’s answer here. Read the changes, approve each file, then save or download them.
  3. Test in VS CodeRun your project and check what happened. Record a checkpoint: a note of your test and result.

Your files stay on this device. You choose what to copy into your AI chat. Code Bridge does not connect to AI or run your project.

File limits & skipped files
Images and other binary files, hidden files, dependency and build folders, lock files, minified scripts, files named for credentials, and files over 512 KB. The limit is 400 source files and 8 MB total. Check selected code for private information before copying.
