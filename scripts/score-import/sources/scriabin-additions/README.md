# Additional Scriabin scores

Retrieved 2026-11-12 from the Mutopia Project. These LilyPond files are
unmodified source editions; both typesetters place their editions in the public
domain. Imported notation is in `data/score-library.json`.

| Score | Typesetter / edition | Source |

## Reproduce

Copy these `.ly` files to a temporary directory. With LilyPond 2.26, run
`convert-ly -e` on each copy, then run LilyPond with
`-dinclude-settings=/absolute/repository/scripts/score-import/dump.ly -dbackend=null`.
Run `events2score.py` on each `.events` file with
`--staves "Right hand,Left hand"`. Remove `measures` and a zero pickup, retain
nonzero pickups, and add the library metadata and guides. Practice tempos are
classroom settings, not claims about performance tempo.

Compare with the MIDI generated by that same LilyPond invocation using
`midinotes.py` and `verify-midi.mjs`:

- Prelude: 472/472 notes; zero missing, extra, or duration differences.
  The pickup is 0.8 quarter-note beats, and the final partial bar completes it.
- Étude: 1,104 non-grace notes against 1,116 MIDI notes, with 12 short
  ornament notes excluded by the verifier's grace-note comparison. Zero extra
  notes and one duration difference in the final accompaniment passage.
  The converter reports one trailing grace note dropped from a secondary voice;
  this source uses hidden notes in separate voices to attach ornaments to chords.
  The printed source remains the reference for ornament placement. Classroom
  playback does not reproduce a pianist's grace timing or expressive rubato.

All 45 written étude bars and the prelude's pickup plus 25 numbered bars are
included. These additions use the existing arrangement and playback engine.
