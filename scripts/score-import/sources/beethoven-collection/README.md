# Beethoven collection additions

Retrieved 2026-11-14. These **sixteen additions** bring Beethoven's workspace to **23 playable scores**:
22 complete pieces or movements, plus the existing clearly labeled Ode to Joy theme excerpt.
The original seven library entries remain unchanged.

The additions include all three Pathétique movements, the first two Tempest movements,
both Für Therese movements, both Op. 49 sonatas, all three Op. 79 movements,
and Bagatelles Op. 119 Nos. 10 and 11. This selection does not contain Tempest's third movement.

## Reproduce and verify

Requires LilyPond / convert-ly 2.26.0, Node, and Python with `mido` and `verovio` (tested with
Verovio 6.4.1). Use that Python to invoke the script so the independent MEI checks can import Verovio:

```sh
PYTHON=/path/to/python-with-mido-and-verovio \
  /path/to/python-with-mido-and-verovio \
  scripts/score-import/sources/beethoven-collection/reproduce.py /tmp/beethoven-scores
```

Optional score IDs after the output directory restrict the run. This copies archived sources to
temporary directories, updates LilyPond syntax, dumps notation events, converts them to score-engine
notation, renders LilyPond MIDI, and compares attacks and durations. It never edits the source archives
or library. For the Bagatelles it also renders MIDI directly from the original MEI using Verovio,
providing an independent check of pitches, rhythms, repeated endings and ties after conversion.
`verification.txt` preserves both sets of reports. Every converted key, time, pickup and staff was
also compared with the final library after classroom metadata was added.

### Import adjustments and limits

- **Pathétique I:** the source's 128th notes remain 128ths. Import, playback, five beams, isolated
  up/down flags and rests are supported using glyphs from the vendored Bravura font (SIL OFL).
- **Für Therese I:** the event dump reports its 4/4 change during the last timestep of the fourth
  slow 2/4 bar. Move that metadata event from whole-note moment 7/4 to 2 so it applies to bar 5.
  No pitches, attacks or rhythms are changed.
- **Tempest I and II; Für Therese II:** temporary cadenza markers preserve each free-time passage
  as one practice bar rather than creating a new bar at every note. These practice-bar numbers and
  separately displayed repeat endings can differ from the printed source. The subtitles and guides
  identify the free-time practice bars; all notes and their written proportional timing are retained.
- **Short final bars:** the converter now writes an explicit length for a final partial bar,
  so hidden empty voices use that same length instead of a whole metrical bar.
- **Bagatelles:** `mei_to_lily.py` is a restricted MEI reader for these two editions. It retains
  sounding pitch spellings, durations, layers, ties, repeats, numbered endings, staccato and written
  trill signs. Implicit gaps in shorter layers become hidden rests. Unsupported musical node types
  fail explicitly. Slurs, hairpins and textual expression remain in the linked edition rather than
  being synthesized by this converter; the interactive version is a study score, not a facsimile.
- **Bagatelle No. 11, bars 8–9:** three held notes split into two voices. Normalize the interactive
  voices so all three ties continue correctly. LilyPond MIDI re-strikes E5/G5 at beat 32 and B-flat5
  at beat 33 when crossing those voices; the independent Verovio comparison of the original MEI
  confirms the held version with **423/423 performed attacks and no duration differences**.
- **Bagatelle No. 10:** both LilyPond and independent MEI comparisons match every attack. Verovio
  sustains notes carrying the source's staccato signs; the interactive player shortens them, which
  explains the independent comparator's reported duration differences.

All fourteen Mutopia conversions match main-note attacks with no extra attacks. Written grace
notes remain in the notation; LilyPond steals small amounts of time from neighboring notes when
rendering them, so its unmatched short ornament attacks are reported separately. Pathétique II
has two duration differences from overlapping unisons in MIDI; independent written voices are retained.
Ornament signs are not fully realized trills. The player uses a steady selected practice tempo;
concert performances also shape tempo changes, fermatas, rubato, pedaling and free-time passages.
