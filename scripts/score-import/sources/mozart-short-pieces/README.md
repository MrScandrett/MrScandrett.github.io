# Short Mozart studies

Retrieved 2026-11-10 from Mutopia. Both editions declare Public Domain in their headers.

- `menuet_k2.ly`: Nicolas Morant, Mutopia 1770, complete 24-bar Minuet K. 2. https://www.mutopiaproject.org/ftp/MozartWA/KV2/menuet_k2/
- `no2-lys.zip`: Han-Wen Nienhuys, Mutopia 391, Duet K. 487 No. 2. https://www.mutopiaproject.org/ftp/MozartWA/KV487/no2/

The score-library entries were transcribed manually from these LilyPond sources, preserving pitches, durations, and repeats. The duet includes the 24-bar minuet only and is labelled as an excerpt; the separate Trio is in the linked PDF. Slurs and the K. 2 fermata are not encoded. Duet appoggiaturas use the engine's grace-note playback. These additions have not been through the LilyPond/MIDI comparison pipeline.
